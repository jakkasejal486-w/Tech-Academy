HTML Lesson 4: Semantic Elements and HTML5

1. Introduction

HTML5 is the modern version of HTML used to create and structure webpages.

HTML5 introduced many new elements that make webpages more meaningful, organized and easier to understand.

In this lesson, we will learn about semantic elements, non-semantic elements, HTML5 elements, audio, video, iframe and other important HTML5 features.

2. What are Semantic Elements?

Semantic elements are HTML elements that clearly describe the meaning and purpose of their content.

For example, <header> represents the header section of a webpage and <footer> represents the footer section.

Semantic elements make the structure of a webpage easier for developers, browsers and search engines to understand.

3. Important Semantic Elements

Element Purpose
<header> Defines the header of a webpage or section
<nav> Defines navigation links
<main> Defines the main content
<section> Defines a section of content
<article> Defines independent content
<aside> Defines related or side content
<footer> Defines the footer of a webpage or section
<figure> Groups images or illustrations
<figcaption> Provides a caption for a figure

4. The Header Element

The <header> element represents introductory content or the header of a webpage or section.

Example

<header>

<h1>Online Tech Learning Academy</h1>

<p>Learn Technology Online</p>

</header>

5. The Nav Element

The <nav> element is used to define a section containing navigation links.

Example

<nav>

<a href="index.html">Home</a>

<a href="courses.html">Courses</a>

<a href="contact.html">Contact</a>

</nav>

The navigation bar in your Online Tech Learning Academy project is an example of the <nav> element.

6. The Main Element

The <main> element represents the main content of a webpage.

Example

<main>

<h1>HTML Course</h1>

<p>Learn HTML from beginner to advanced level.</p>

</main>

7. The Section Element

The <section> element is used to group related content into a section.

Example

<section>

<h2>HTML Course</h2>

<p>Learn the basics of HTML.</p>

</section>

8. The Article Element

The <article> element represents independent and self-contained content.

It can be used for blog posts, news articles, course information and other independent content.

Example

<article>

<h2>Introduction to HTML</h2>

<p>HTML is used to create the structure of webpages.</p>

</article>

9. The Aside Element

The <aside> element contains content that is related to the main content but is not part of the main flow.

Example

<aside>

<h3>Related Courses</h3>

<p>You can also learn CSS and JavaScript.</p>

</aside>

10. The Footer Element

The <footer> element represents the bottom section of a webpage or section.

Example

<footer>

<p>© 2026 Online Tech Learning Academy</p>

</footer>

11. The Figure Element

The <figure> element is used to group an image, diagram, illustration or other content.

Example

<figure>

<img src="html.jpg" alt="HTML Course">

</figure>

12. The Figcaption Element

The <figcaption> element provides a caption for content inside a <figure>.

Example

<figure>

<img src="html.jpg" alt="HTML Course">

<figcaption>
HTML Course
</figcaption>

</figure>

13. Complete Semantic HTML Structure

A webpage can be organized using multiple semantic elements.

Example

<!DOCTYPE html>

<html>

<head>

<title>Online Tech Learning Academy</title>

</head>

<body>

<header>

<h1>Online Tech Learning Academy</h1>

</header>

<nav>

<a href="index.html">Home</a>

<a href="courses.html">Courses</a>

<a href="contact.html">Contact</a>

</nav>

<main>

<section>

<h2>HTML Course</h2>

<p>Learn HTML from basic to advanced concepts.</p>

</section>

<article>

<h2>HTML Lesson 1</h2>

<p>Introduction to HTML and basic HTML elements.</p>

</article>

<aside>

<h3>Related Courses</h3>

<p>CSS and JavaScript</p>

</aside>

</main>

<footer>

<p>© 2026 Online Tech Learning Academy</p>

</footer>

</body>

</html>

14. Semantic vs Non-Semantic Elements

Semantic elements clearly describe their purpose, while non-semantic elements do not describe what their content means.

Semantic Element Non-Semantic Element
<header> <div>
<nav> <span>
<main> <div>
<section> <div>
<article> <div>
<footer> <div>

15. The Div Element

The <div> element is a generic container used to group HTML elements.

It does not describe the meaning of its content.

Example

<div>

<h2>HTML Course</h2>

<p>Learn HTML.</p>

</div>

16. The Span Element

The <span> element is an inline container commonly used to style or manipulate a small part of text.

Example

<p>

Learn <span>HTML</span> today.

</p>

17. HTML5 Audio

HTML5 provides the <audio> element to add audio to a webpage.

Example

<audio controls>

<source src="audio.mp3" type="audio/mpeg">

Your browser does not support the audio element.

</audio>

The controls attribute displays audio controls such as play, pause and volume.

18. Audio Attributes

Attribute Purpose
controls Displays audio controls
autoplay Attempts to start playback automatically
loop Repeats the audio
muted Starts the audio muted
preload Provides a hint about how the browser should load the audio

19. HTML5 Video

The <video> element is used to add videos to webpages.

Example

<video width="500" controls>

<source src="course.mp4" type="video/mp4">

Your browser does not support the video element.

</video>

20. Video Attributes

Attribute Purpose
controls Displays video controls
width Specifies video width
height Specifies video height
autoplay Attempts to start playback automatically
loop Repeats the video
muted Starts the video muted
poster Specifies an image shown before video playback

21. Video with Poster Image

The poster attribute specifies an image displayed before the video starts playing.

Example

<video width="500" controls poster="thumbnail.jpg">

<source src="html-course.mp4" type="video/mp4">

</video>

22. HTML Iframe

The <iframe> element is used to embed another webpage or supported external content inside the current webpage.

Example

<iframe
src="https://www.example.com"
width="600"
height="400">
</iframe>

23. Embedding a YouTube Video

An iframe can be used to embed a supported YouTube video on a webpage.

Example

<iframe
width="560"
height="315"
src="https://www.youtube.com/embed/VIDEO_ID"
title="HTML Tutorial"
allowfullscreen>
</iframe>

24. HTML Comments

Comments are notes written inside HTML code that are not displayed as webpage content.

Syntax

<!-- This is an HTML comment -->

Example

<!-- Navigation section -->

<nav>

<a href="index.html">Home</a>

</nav>

Comments are useful for explaining and organizing code.

25. HTML Entities

HTML entities are special codes used to display reserved characters and special symbols in HTML.

Entity Character
&lt; <
&gt; >
&amp; &
&quot; "
&copy; ©
&reg; ®

26. HTML5 Doctype

The HTML5 doctype declaration is written at the beginning of an HTML document.

Syntax

<!DOCTYPE html>

It tells the browser that the document should be interpreted as HTML.

27. HTML5 Character Encoding

UTF-8 is commonly specified using the <meta charset="UTF-8"> element.

Example

<meta charset="UTF-8">

It allows webpages to correctly represent a wide range of characters and symbols.

28. Complete HTML5 Page Structure

<!DOCTYPE html>

<html>

<head>

<meta charset="UTF-8">

<meta name="viewport"
content="width=device-width, initial-scale=1.0">

<title>Online Tech Learning Academy</title>

</head>

<body>

<header>

<h1>Online Tech Learning Academy</h1>

</header>

<nav>

<a href="index.html">Home</a>

<a href="courses.html">Courses</a>

<a href="contact.html">Contact</a>

</nav>

<main>

<section>

<h2>HTML Course</h2>

<p>
Learn HTML from basic to advanced concepts.
</p>

</section>

<article>

<h2>Lesson 4</h2>

<p>
Learn semantic HTML and HTML5 elements.
</p>

</article>

</main>

<footer>

<p>
© 2026 Online Tech Learning Academy
</p>

</footer>

</body>

</html>

29. Advantages of Semantic HTML

  • Creates a clear webpage structure.
  • Makes HTML code easier to understand.
  • Helps search engines understand webpage content.
  • Improves accessibility for users of assistive technologies.
  • Makes websites easier to maintain.
  • Provides meaningful names for different parts of a webpage.

30. Important HTML5 Elements

Element Purpose
<header> Page or section header
<nav> Navigation links
<main> Main webpage content
<section> Groups related content
<article> Independent content
<aside> Related side content
<footer> Page or section footer
<figure> Groups media or illustrations
<figcaption> Caption for a figure
<audio> Adds audio
<video> Adds video
<iframe> Embeds supported external content

31. Important Points to Remember

  1. Semantic elements clearly describe the purpose of their content.
  2. The <header> element represents introductory content.
  3. The <nav> element contains navigation links.
  4. The <main> element contains the main content.
  5. The <section> element groups related content.
  6. The <article> element represents independent content.
  7. The <aside> element contains related side content.
  8. The <footer> element represents footer content.
  9. The <figure> element groups images or illustrations.
  10. The <figcaption> element provides a caption.
  11. The <div> element is a general-purpose container.
  12. The <span> element is an inline container.
  13. The <audio> element adds audio to a webpage.
  14. The <video> element adds video to a webpage.
  15. The <iframe> element can embed another webpage or supported external content.
  16. The <!-- --> syntax creates an HTML comment.
  17. The <!DOCTYPE html> declaration is used at the beginning of an HTML document.
  18. The <meta charset="UTF-8"> element specifies the character encoding.

Lesson Summary

In this lesson, you learned about semantic HTML elements and important HTML5 features.

You learned how to use <header>, <nav>, <main>, <section>, <article>, <aside> and <footer> to create a meaningful webpage structure.

You also learned how to add audio and video, embed external content using iframes, write comments and use HTML entities.
