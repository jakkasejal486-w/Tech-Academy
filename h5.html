HTML Lesson 5: Forms and Input Elements

1. Introduction to HTML Forms

HTML forms are used to collect information from users and send that information to a server for processing.

Forms are commonly used for registration, login, contact forms, search boxes, feedback forms, surveys and online applications.

In your Online Tech Learning Academy project, the registration and login pages can use HTML forms to collect student information.

2. The Form Element

The <form> element is used to create an HTML form.

Basic Syntax

<form>

Form elements go here.

</form>

Example

<form>

<label>Name:</label>

<input type="text">

</form>

3. Form Attributes

The <form> element can use different attributes to control how form data is submitted.

Attribute Purpose
action Specifies where the form data should be sent.
method Specifies how the form data should be sent.
autocomplete Controls whether the browser can automatically complete form values.
target Specifies where the response should be displayed.
enctype Specifies how form data should be encoded when submitted.

4. The Action Attribute

The action attribute specifies the location where the form data will be submitted.

Example

<form action="register.php">

<label>Name:</label>

<input type="text" name="name">

<input type="submit" value="Register">

</form>

In this example, the form data is sent to register.php.

5. The Method Attribute

The method attribute specifies the HTTP method used to send form data.

The two commonly used methods are GET and POST.

Method Description
GET Sends form data as part of the URL.
POST Sends form data in the request body.

6. GET Method

The GET method sends form data through the URL.

Example

<form action="search.php" method="get">

<label>Search:</label>

<input type="text" name="search">

<input type="submit" value="Search">

</form>

GET is commonly used for search forms and requests where the submitted values can safely appear in the URL.

7. POST Method

The POST method sends form data in the body of the HTTP request instead of placing the values in the URL.

Example

<form action="register.php" method="post">

<label>Name:</label>

<input type="text" name="name">

<input type="submit" value="Register">

</form>

POST is commonly used when submitting registration, login or other data that should not be placed in the URL.

8. The Label Element

The <label> element provides a description for a form control.

Example

<label for="name">Full Name:</label>

<input type="text" id="name" name="name">

The for attribute of the label should match the id of the related input.

9. Text Input

The input element with type="text" creates a single-line text input.

Example

<label for="name">Full Name:</label>

<input type="text" id="name" name="name">

10. The Name Attribute

The name attribute identifies a form control when its value is submitted.

Example

<input type="text" name="username">

The server can use the name username to access the submitted value.

11. The ID Attribute

The id attribute uniquely identifies an HTML element.

Example

<label for="email">Email:</label>

<input type="email" id="email" name="email">

12. Password Input

The password input type is used to create a field where characters are hidden while the user types.

Example

<label for="password">Password:</label>

<input type="password" id="password" name="password">

13. Email Input

The email input type is used for entering an email address.

Example

<label for="email">Email:</label>

<input type="email" id="email" name="email">

Browsers can perform basic validation for email input.

14. Number Input

The number input type is used for numerical values.

Example

<label for="age">Age:</label>

<input type="number" id="age" name="age">

15. Date Input

The date input type allows the user to select a date.

Example

<label for="dob">Date of Birth:</label>

<input type="date" id="dob" name="dob">

16. Radio Buttons

Radio buttons allow the user to select one option from a group of related options.

Example

<p>Select Gender:</p>

<input type="radio" id="male" name="gender" value="male">
<label for="male">Male</label>

<input type="radio" id="female" name="gender" value="female">
<label for="female">Female</label>

Radio buttons should have the same name when only one option should be selected.

17. Checkboxes

Checkboxes allow users to select one or more options.

Example

<p>Select Skills:</p>

<input type="checkbox" id="html" name="skills" value="html">
<label for="html">HTML</label>

<input type="checkbox" id="css" name="skills" value="css">
<label for="css">CSS</label>

<input type="checkbox" id="javascript" name="skills" value="javascript">
<label for="javascript">JavaScript</label>

18. Submit Button

The submit button is used to submit the form.

Example

<input type="submit" value="Register">

19. Reset Button

The reset button resets the form controls to their initial values.

Example

<input type="reset" value="Reset">

20. Button Element

The <button> element creates a clickable button.

Example

<button type="submit">Register</button>

21. Placeholder Attribute

The placeholder attribute provides a short hint about the expected value.

Example

<input
type="text"
name="username"
placeholder="Enter your username">

22. Required Attribute

The required attribute specifies that a form field must be completed before the form can be submitted.

Example

<input
type="text"
name="name"
required>

23. Minlength and Maxlength

The minlength attribute specifies the minimum number of characters allowed.

The maxlength attribute specifies the maximum number of characters allowed.

Example

<input
type="text"
name="username"
minlength="5"
maxlength="20">

24. Min and Max

The min and max attributes specify the minimum and maximum allowed values for suitable input types.

Example

<input
type="number"
name="age"
min="18"
max="60">

25. Select Element

The <select> element creates a drop-down list.

Example

<label for="course">Select Course:</label>

<select id="course" name="course">

<option value="html">HTML</option>

<option value="css">CSS</option>

<option value="javascript">JavaScript</option>

<option value="python">Python</option>

</select>

26. Textarea Element

The <textarea> element is used to create a multi-line text input field.

Example

<label for="message">Message:</label>

<textarea
id="message"
name="message"
rows="5"
cols="40">
</textarea>

27. File Upload

The file input type allows the user to select a file from their device.

Example

<label for="resume">Upload Resume:</label>

<input
type="file"
id="resume"
name="resume">

28. Color Input

The color input type allows the user to select a color.

Example

<label for="color">Choose Color:</label>

<input
type="color"
id="color"
name="color">

29. Range Input

The range input type creates a slider for selecting a numerical value within a specified range.

Example

<label for="rating">Rating:</label>

<input
type="range"
id="rating"
name="rating"
min="1"
max="10">

30. Search Input

The search input type is designed for entering search terms.

Example

<input
type="search"
name="search"
placeholder="Search courses">

31. URL Input

The url input type is used for entering a web address.

Example

<label for="website">Website:</label>

<input
type="url"
id="website"
name="website"

The tel input type is used for entering telephone numbers.

Example

<label for="phone">Phone Number:</label>

<input
type="tel"
id="phone"
name="phone"
placeholder="Enter phone number">

33. Hidden Input

The hidden input type stores a value in the form without displaying the field to the user.

Example

<input
type="hidden"
name="course"
value="HTML">

34. Disabled Input

The disabled attribute makes a form control unavailable for interaction.

Example

<input
type="text"
value="Not Available"
disabled>

35. Readonly Input

The readonly attribute prevents the user from editing the value of an input field.

Example

<input
type="text"
value="HTML Course"
readonly>

36. Fieldset Element

The <fieldset> element groups related form controls together.

Example

<fieldset>

<legend>Student Information</legend>

<label>Name:</label>

<input type="text" name="name">

<label>Email:</label>

<input type="email" name="email">

</fieldset>

37. Legend Element

The <legend> element defines a caption for a <fieldset>.

Example

<fieldset>

<legend>Login Details</legend>

<input type="email" name="email">

<input type="password" name="password">

</fieldset>

41. Client-Side Form Validation

HTML provides basic validation features that can help prevent incomplete or incorrectly formatted data from being submitted.

Example

<form>

<label>Email:</label>

<input
type="email"
name="email"
required>

<label>Password:</label>

<input
type="password"
name="password"
minlength="8"
required>

<button type="submit">
Login
</button>

</form>

The browser can check the required fields and basic email format before submitting the form.

42. Form and Backend

HTML is responsible for creating the form interface. A backend language such as PHP can process the submitted form data.

For example, a registration form can send its data to a PHP file.

HTML

<form action="register.php" method="post">

<input type="text" name="name">

<input type="email" name="email">

<button type="submit">
Register
</button>

</form>

PHP Example

<?php

$name=$_POST["name"];

$email=$_POST["email"];

echo "Name: ".$name;

echo "Email: ".$email;

?>

This demonstrates the basic connection between an HTML form and a PHP backend.

43. Form and Database

In a complete web application, form data can be processed by the backend and stored in a database.

For example, a student registration form can collect the student's name, email and course and send the data to PHP. PHP can then validate the data and store it in a database such as MySQL.

Basic Flow

  1. User opens the registration form.
  2. User enters their information.
  3. User clicks the Register button.
  4. HTML sends the form data to the backend.
  5. PHP receives and validates the data.
  6. PHP communicates with the database.
  7. The database stores the information.
  8. The user receives a success or error message.
