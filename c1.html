CSS Lesson 1: Introduction, Syntax and Selectors

1. Introduction to CSS

CSS stands for Cascading Style Sheets.

CSS is a stylesheet language used to style and design HTML webpages.

HTML is mainly used to create the structure of a webpage, while CSS is used to control its appearance and layout.

With CSS, we can change colors, fonts, sizes, spacing, borders, backgrounds, positioning and many other visual properties.

2. Why Do We Use CSS?

Without CSS, webpages would mostly contain plain HTML content with very little visual styling.

CSS allows developers to create attractive, organized and user-friendly webpages.

CSS can be used to:

  • Change text colors.
  • Change background colors.
  • Change font size and font style.
  • Add borders.
  • Add margins and padding.
  • Control the width and height of elements.
  • Align text and elements.
  • Create layouts.
  • Design navigation bars.
  • Create responsive webpages.
  • Add hover effects and transitions.

3. CSS Example

Consider the following HTML code:


<h1> Online Tech Learning Academy</h1>

<p>Learn Technology Online</p>

We can use CSS to style these elements.

h1{
color:#40E0D0;
text-align:center;
}

p{
color:white;
font-size:18px;
}

4. Basic CSS Syntax

A CSS rule consists of a selector, property and value.

Syntax

selector{
property:value;
}

Example

h1{
color:blue;
font-size:30px;
}

Here, h1 is the selector.

color and font-size are properties.

blue and 30px are values.

5. CSS Selector

A selector is used to select the HTML element that we want to style.

Example

p{
color:white;
}

Here, p selects all paragraph elements.

6. CSS Property

A CSS property defines what aspect of an HTML element we want to change.

Examples

color

background-color

font-size

font-family

margin

padding

width

height

border

7. CSS Value

A value specifies how the selected property should be applied.

Example


    p{
color:red;
}

In this example, red is the value of the color property.

8. CSS Declaration

A property and its value together form a CSS declaration.

Example

color:red;

Here, color:red; is one CSS declaration.

9. Multiple CSS Declarations

We can use multiple declarations inside one CSS rule.

Example

h1{
color:#40E0D0;
font-size:35px;
text-align:center;
font-family:Arial;
}

10. Types of CSS

There are three main ways to apply CSS to an HTML document.

  1. Inline CSS
  2. Internal CSS
  3. External CSS

11. Inline CSS

Inline CSS is written directly inside an HTML element using the style attribute.

Example

<h1 style="color:#40E0D0;">
Online Tech Learning Academy
</h1>

Inline CSS affects only the particular HTML element where it is written.

12. Advantages of Inline CSS

  • Easy to apply to a single element.
  • Useful for quick testing.
  • Does not require a separate CSS file.

13. Disadvantages of Inline CSS

  • Creates repetitive code.
  • Difficult to maintain for large websites.
  • Makes HTML code less clean.
  • Not suitable for styling many pages.

14. Internal CSS

Internal CSS is written inside the <style> element in the <head> section of an HTML document.

Example

<!DOCTYPE html>

<html>

<head>

<style>

h1{
color:#40E0D0;
text-align:center;
}

p{
color:white;
}

</style>

</head>

<body>

<h1>My Website</h1>

<p>Welcome to my website.</p>

</body>

</html>

15. External CSS

External CSS is written in a separate CSS file and connected to an HTML document using the <link> element.

HTML File

<!DOCTYPE html>

<html>

<head>

<link rel="stylesheet" href="style.css">

</head>

<body>

<h1>Online Tech Learning Academy</h1>

</body>

</html>

style.css

h1{
color:#40E0D0;
text-align:center;
}

16. Advantages of External CSS

  • Keeps HTML and CSS separate.
  • Makes code easier to maintain.
  • One CSS file can style multiple HTML pages.
  • Reduces repeated CSS code.
  • Makes large websites easier to manage.

17. Comparison of CSS Types

Type Where It Is Written Best Use
Inline CSS Inside HTML element Single element
Internal CSS Inside <style> Single webpage
External CSS Separate .css file Multiple webpages

18. Element Selector

The element selector selects HTML elements based on their tag name.

Example

p{
color:white;
}

h1{
color:#40E0D0;
}

The first rule selects all <p> elements.

The second rule selects all <h1> elements.

19. Class Selector

The class selector selects HTML elements that have a particular class attribute.

A class selector starts with a dot ..

Example

.heading{
color:#40E0D0;
text-align:center;
}

HTML

<h1 class="heading">
Welcome
</h1>

20. Using the Same Class on Multiple Elements

The same class can be applied to multiple HTML elements.

Example

.important{
color:#40E0D0;
font-weight:bold;
}
<h2 class="important">
HTML
</h2>

<p class="important">
Learn HTML.
</p>

21. ID Selector

The ID selector selects an element using its unique id attribute.

An ID selector starts with the hash symbol #.

Example

#main-title{
color:#40E0D0;
text-align:center;
}

HTML

<h1 id="main-title">
Online Tech Learning Academy
</h1>

22. Class Selector vs ID Selector

Class ID
Starts with . Starts with #
Can be used on multiple elements. Should identify a unique element.
Example: .heading Example: #heading

23. Universal Selector

The universal selector selects all HTML elements.

It is represented by the * symbol.

Example

*{
box-sizing:border-box;
margin:0;
padding:0;
}

24. Grouping Selector

The grouping selector allows multiple selectors to share the same CSS rules.

Example

h1,h2,h3{
color:#40E0D0;
}

This applies the same color to all h1, h2 and h3 elements.

25. Descendant Selector

The descendant selector selects elements that are inside another element.

Example

div p{
color:#40E0D0;
}

This selects paragraph elements that are inside a div.

26. Child Selector

The child selector selects elements that are direct children of another element.

Example

div>p{
color:#40E0D0;
}

This selects only paragraphs that are direct children of the div.

27. Attribute Selector

The attribute selector selects HTML elements based on their attributes.

Example

input[type="text"]{
border:2px solid #40E0D0;
}

This selects input elements whose type is text.

28. Pseudo-Class Selector

A pseudo-class is used to define a special state of an HTML element.

One of the most commonly used pseudo-classes is :hover.

Example

a:hover{
color:white;
}

This changes the link color when the mouse pointer is placed over the link.

29. CSS Comments

CSS comments are used to add notes inside CSS code.

Syntax

/* This is a CSS comment */

Example

/* Navigation bar */

nav{
background-color:#1e3a5f;
}

Comments are not displayed on the webpage.

30. CSS Colors

The color property is used to change the color of text.

Example

h1{
color:#40E0D0;
}

CSS supports different ways of specifying colors.

Color Name

h1{
color:red;
}

Hexadecimal Color

h1{
color:#40E0D0;
}

RGB Color

h1{
color:rgb(64,224,208);
}

31. Background Color

The background-color property changes the background color of an element.

Example

body{
background-color:black;
}

nav{
background-color:#1e3a5f;
}

32. Text Alignment

The text-align property controls the horizontal alignment of text.

Example

h1{
text-align:center;
}

Common values include left, center, right and justify.

33. Font Size

The font-size property controls the size of text.

Example

p{
font-size:18px;
}

34. Font Family

The font-family property specifies the typeface used for text.

Example

body{
font-family:Arial,sans-serif;
}

35. Font Weight

The font-weight property controls the thickness of text.

Example

h1{
font-weight:bold;
}

36. Text Decoration

The text-decoration property adds or removes decorations such as underlines.

Example

a{
text-decoration:none;
}

37. CSS Selector Summary

Selector Example Purpose
Element p Selects all paragraph elements
Class .box Selects elements with class box
ID #header Selects an element with a specific ID
Universal * Selects all elements
Grouping h1,h2 Selects multiple elements
Descendant div p Selects paragraphs inside div
Child div>p Selects direct child paragraphs
Attribute input[type="text"] Selects elements by attribute
Pseudo-class a:hover Selects an element in a special state

38. Complete CSS Example

The following example combines HTML and CSS.

<!DOCTYPE html>

<html>

<head>

<title>CSS Example</title>

<style>

*{
box-sizing:border-box;
}

body{
background-color:black;
font-family:Arial,sans-serif;
}

h1{
color:#40E0D0;
text-align:center;
font-size:35px;
}

p{
color:white;
font-size:18px;
}

.box{
background-color:#1e3a5f;
padding:20px;
border:2px solid #40E0D0;
}

#special{
color:#40E0D0;
font-weight:bold;
}

a:hover{
color:white;
}

</style>

</head>

<body>

<h1>
Online Tech Learning Academy
</h1>

<p>
Learn CSS from basic to advanced concepts.
</p>

<div class="box">

<p id="special">
CSS makes webpages attractive.
</p>

</div>

</body>

</html>

40. Important Points to Remember

  1. CSS stands for Cascading Style Sheets.
  2. CSS is used to style HTML webpages.
  3. A CSS rule contains a selector and declarations.
  4. A declaration contains a property and a value.
  5. There are three main types of CSS: inline, internal and external.
  6. External CSS is useful for larger websites and multiple webpages.
  7. An element selector selects HTML elements by their tag name.
  8. A class selector starts with a dot.
  9. An ID selector starts with a hash symbol.
  10. The universal selector is represented by *.
  11. Grouping selectors allow multiple elements to share CSS rules.
  12. CSS comments are written between /* and */.
  13. The color property changes text color.
  14. The background-color property changes background color.
  15. The font-size property changes text size.
  16. The font-family property specifies the font.
  17. The text-align property controls text alignment.
  18. The :hover pseudo-class is used for hover effects.
