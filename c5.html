CSS Lesson 5: Responsive Design and Advanced Styling

1. Introduction to Responsive Web Design

Responsive Web Design is a technique used to make websites display properly on different screen sizes and devices.

A responsive website can automatically adjust its layout according to the device being used.

For example, the same website should work properly on:

  • Desktop computers
  • Laptops
  • Tablets
  • Mobile phones

2. Why Responsive Design is Important

Users access websites from different devices and screen sizes.

If a website is designed only for a desktop screen, it may look incorrect on a mobile phone.

Responsive design helps improve:

  • User experience
  • Readability
  • Navigation
  • Accessibility
  • Mobile usability

3. Viewport Meta Tag

The viewport meta tag helps browsers control the dimensions and scaling of a webpage on mobile devices.

Example

<meta name="viewport" content="width=device-width, initial-scale=1.0">

This is normally placed inside the <head> section of an HTML document.

4. Media Queries

Media queries are one of the most important features of responsive CSS.

They allow different CSS rules to be applied depending on screen size, device characteristics or other conditions.

Basic Syntax

@media(max-width:600px){

body{
background-color:black;
}

}

5. Max Width

max-width applies CSS rules when the screen width is less than or equal to the specified value.

Example

@media(max-width:600px){

h1{
font-size:25px;
}

}

6. Min Width

min-width applies CSS rules when the screen width is greater than or equal to the specified value.

Example

@media(min-width:768px){

.container{
width:80%;
}

}

7. Common Screen Sizes

Device Common Width
Mobile Up to 600px
Tablet 601px - 900px
Laptop 901px - 1200px
Desktop Above 1200px

8. Responsive Text

Text sizes can be changed for smaller screens using media queries.

Example

h1{
font-size:40px;
}

@media(max-width:600px){

h1{
font-size:25px;
}

}

9. Responsive Images

Images should be able to shrink according to the available screen width.

Example

img{
max-width:100%;
height:auto;
}

This prevents images from becoming wider than their containing element.

10. Responsive Width

Using percentages instead of fixed pixel values can make layouts more flexible.

Example

.container{
width:90%;
margin:auto;
}

11. Max Width Container

The max-width property can prevent content from becoming too wide on large screens.

Example

.container{
width:90%;
max-width:1100px;
margin:auto;
}

12. CSS Units

CSS provides different units for specifying sizes.

Unit Description
px Pixels.
% Percentage relative to another value.
em Relative to the font size of the element or its context.
rem Relative to the root element's font size.
vw Relative to viewport width.
vh Relative to viewport height.

13. Pixel Unit

The px unit represents pixels.

Example

h1{
font-size:30px;
}

14. Percentage Unit

The percentage unit is relative to the size of another element or property.

Example

.box{
width:80%;
}

15. Viewport Width

vw means viewport width.

1vw represents 1% of the viewport width.

Example

h1{
font-size:5vw;
}

16. Viewport Height

vh means viewport height.

1vh represents 1% of the viewport height.

Example

.section{
height:100vh;
}

17. CSS Variables

CSS variables allow commonly used values to be stored and reused throughout a stylesheet.

Example

:root{
--main-color:#40E0D0;
--background-color:black;
}

h1{
color:var(--main-color);
}

body{
background-color:var(--background-color);
}

18. Benefits of CSS Variables

  • Reduce repeated code.
  • Make CSS easier to maintain.
  • Allow common values to be changed easily.
  • Improve consistency throughout a website.

19. CSS Transitions

The transition property creates smooth changes between CSS property values.

Example

button{
background-color:#1e3a5f;
transition:0.3s;
}

button:hover{
background-color:#40E0D0;
}

20. Transition Property

A transition can specify the property, duration and timing function.

Example

button{
transition:background-color 0.3s ease;
}

21. CSS Transform

The transform property allows an element to be moved, rotated, scaled or skewed.

Example

.box{
transform:scale(1.1);
}

22. Translate

translate moves an element from its original position.

Example

.box{
transform:translateX(20px);
}

23. Rotate

rotate rotates an element.

Example

.box{
transform:rotate(10deg);
}

24. Scale

scale increases or decreases the size of an element.

Example

.box{
transform:scale(1.2);
}

25. Hover Effects

The :hover pseudo-class applies CSS when the mouse pointer moves over an element.

Example

button:hover{
background-color:#40E0D0;
color:#1e3a5f;
}

26. Transition and Hover Together

Transitions can be combined with hover effects to create smooth animations.

Example

button{
background-color:#1e3a5f;
color:#40E0D0;
transition:0.3s;
}

button:hover{
background-color:#40E0D0;
color:#1e3a5f;
transform:scale(1.05);
}

27. Opacity

The opacity property controls the transparency of an element.

The value can range from 0 to 1.

Example

.box{
opacity:0.5;
}

28. Box Shadow

The box-shadow property adds a shadow around an element.

Example

.card{
box-shadow:0 5px 20px rgba(0,0,0,0.5);
}

29. Text Shadow

The text-shadow property adds a shadow to text.

Example

h1{
text-shadow:2px 2px 5px black;
}

30. Border Radius

The border-radius property creates rounded corners.

Example

.card{
border-radius:15px;
}

31. Cursor Property

The cursor property changes the appearance of the mouse pointer.

Example

button{
cursor:pointer;
}

32. Common Cursor Values

Value Purpose
pointer Shows a pointer cursor.
default Shows the normal cursor.
text Shows a text selection cursor.
move Shows a move cursor.
not-allowed Indicates that an action is not allowed.

33. Object Fit

The object-fit property controls how an image or video fits inside its container.

Example

img{
width:300px;
height:200px;
object-fit:cover;
}

34. Common Object Fit Values

Value Description
fill Stretches the image to fill the container.
contain Shows the complete image inside the container.
cover Fills the container while maintaining aspect ratio.
none Keeps the original image size.

35. Responsive Flexbox

Flexbox can be combined with media queries to create responsive layouts.

Example

.container{
display:flex;
gap:20px;
}

.card{
flex:1;
}

@media(max-width:600px){

.container{
flex-direction:column;
}

.card{
width:100%;
}

}

36. Responsive Navigation Bar

A navigation bar can be adjusted for smaller screens using media queries.

Example

nav{
display:flex;
gap:20px;
}

@media(max-width:600px){

nav{
flex-direction:column;
height:auto;
}

}

37. Responsive Course Cards

Course cards can be made responsive using Flexbox and media queries.

Example

.courses{
display:flex;
gap:20px;
flex-wrap:wrap;
}

.course{
flex:1 1 300px;
padding:25px;
}

@media(max-width:600px){

.course{
flex:1 1 100%;
}

}

38. Complete Responsive Website Example

<!DOCTYPE html>

<html>

<head>

<meta name="viewport" content="width=device-width, initial-scale=1.0">

<title>Responsive Website</title>

<style>

*{
box-sizing:border-box;
}

body{
margin:0;
background-color:black;
color:white;
font-family:Arial,sans-serif;
}

.container{
width:90%;
max-width:1100px;
margin:auto;
}

nav{
background-color:#1e3a5f;
padding:20px;
display:flex;
justify-content:center;
gap:20px;
}

nav a{
color:#40E0D0;
text-decoration:none;
}

.courses{
display:flex;
gap:20px;
flex-wrap:wrap;
margin-top:30px;
}

.card{
flex:1 1 300px;
padding:30px;
background-color:#1e3a5f;
border:2px solid #40E0D0;
border-radius:10px;
text-align:center;
transition:0.3s;
}

.card:hover{
transform:scale(1.05);
}

@media(max-width:600px){

nav{
flex-direction:column;
align-items:center;
}

.card{
flex:1 1 100%;
}

}

</style>

</head>

<body>

<div class="container">

<nav>

<a href="#">HOME</a>

<a href="#">COURSES</a>

<a href="#">LOGIN</a>

</nav>

<div class="courses">

<div class="card">

<h2>HTML</h2>

<p>Learn HTML.</p>

</div>

<div class="card">

<h2>CSS</h2>

<p>Learn CSS.</p>

</div>

<div class="card">

<h2>JavaScript</h2>

<p>Learn JavaScript.</p>

</div>

</div>

</div>

</body>

</html>

39. Important CSS Responsive Design Properties

Property Purpose
max-width Sets the maximum width of an element.
min-width Sets the minimum width of an element.
width Controls the width of an element.
height Controls the height of an element.
max-width:100% Helps images fit inside their containers.
transition Creates smooth property changes.
transform Moves, rotates or scales elements.
opacity Controls transparency.
cursor Changes the mouse cursor.
object-fit Controls how media fits inside its container.
box-shadow Adds a shadow around an element.
text-shadow Adds a shadow to text.

40. Important Points to Remember

  1. Responsive design allows websites to work on different screen sizes.
  2. The viewport meta tag is important for mobile responsive websites.
  3. Media queries allow different CSS rules for different screen sizes.
  4. max-width is commonly used for mobile layouts.
  5. min-width can be used for larger screen layouts.
  6. Percentage, vw and vh units can help create flexible layouts.
  7. Responsive images can use max-width:100%.
  8. CSS variables allow values to be reused throughout a stylesheet.
  9. Transitions create smooth changes between CSS states.
  10. Transform can move, rotate and scale elements.
  11. The :hover pseudo-class is commonly used for interactive effects.
  12. Opacity controls the transparency of an element.
  13. Box shadow creates visual depth around elements.
  14. Object-fit controls how images fit inside their containers.
  15. Flexbox combined with media queries can create responsive layouts.
  16. Responsive design is important for your Online Tech Learning Academy because students may access the website from mobile phones, tablets and computers.
