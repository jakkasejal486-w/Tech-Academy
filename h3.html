HTML Lesson 3: Tables and Forms

1. Introduction

In this lesson, we will learn about HTML Tables and HTML Forms.

Tables are used to display information in rows and columns, while forms are used to collect information from users.

Forms are commonly used for registration, login, contact, feedback, search and other user input activities.

2. What is an HTML Table?

An HTML table is used to display data in the form of rows and columns.

HTML tables are created using the <table> element.

Some important table tags are:

Tag Purpose
<table> Creates a table
<tr> Creates a table row
<th> Creates a table heading
<td> Creates a table data cell
<caption> Adds a title to the table
<thead> Groups table header content
<tbody> Groups table body content
<tfoot> Groups table footer content

3. Creating a Simple Table

The <table> tag is used to create a table.

Example

<table>
<tr>
<th>Name</th>
<th>Course</th>
</tr>

<tr>
<td>Sejal</td>
<td>HTML</td>
</tr>

<tr>
<td>Rahul</td>
<td>CSS</td>
</tr>
</table>

Output

Name Course
Sejal HTML
Rahul CSS

4. Table Rows

The <tr> tag is used to create a table row.

Example

<tr>
<td>HTML</td>
<td>Beginner</td>
</tr>

Each <tr> represents one row in the table.

5. Table Headings

The <th> tag is used to create a heading cell in a table.

Example

<tr>
<th>Student Name</th>
<th>Course</th>
<th>Marks</th>
</tr>

Table headings are normally displayed in bold text by browsers.

6. Table Data

The <td> tag is used to create a normal data cell.

Example

<tr>
<td>Sejal</td>
<td>HTML</td>
<td>90</td>
</tr>

7. Complete Table Example

<!DOCTYPE html>
<html>
<head>
<title>Student Details</title>
</head>

<body>

<h1>Student Details</h1>

<table>

<tr>
<th>Name</th>
<th>Course</th>
<th>Marks</th>
</tr>

<tr>
<td>Sejal</td>
<td>HTML</td>
<td>90</td>
</tr>

<tr>
<td>Rahul</td>
<td>CSS</td>
<td>85</td>
</tr>

<tr>
<td>Priya</td>
<td>JavaScript</td>
<td>92</td>
</tr>

</table>

</body>
</html>

8. Table Caption

The <caption> tag is used to give a title or description to a table.

Example

<table>

<caption>Student Information</caption>

<tr>
<th>Name</th>
<th>Course</th>
</tr>

<tr>
<td>Sejal</td>
<td>HTML</td>
</tr>

</table>

9. Colspan Attribute

The colspan attribute is used to make one cell occupy multiple columns.

Example

<table>

<tr>
<th colspan="2">Student Details</th>
</tr>

<tr>
<td>Name</td>
<td>Sejal</td>
</tr>

</table>

10. Rowspan Attribute

The rowspan attribute is used to make one cell occupy multiple rows.

Example

<table>

<tr>
<th rowspan="2">HTML</th>
<td>Basic</td>
</tr>

<tr>
<td>Advanced</td>
</tr>

</table>

11. Table Head, Body and Footer

HTML provides <thead>, <tbody> and <tfoot> to organize table content.

Example

<table>

<thead>
<tr>
<th>Course</th>
<th>Students</th>
</tr>
</thead>

<tbody>
<tr>
<td>HTML</td>
<td>50</td>
</tr>

<tr>
<td>CSS</td>
<td>40</td>
</tr>
</tbody>

<tfoot>
<tr>
<td>Total</td>
<td>90</td>
</tr>
</tfoot>

</table>

12. What is an HTML Form?

An HTML form is used to collect information from users.

Forms are commonly used for:

  • Registration
  • Login
  • Contact forms
  • Feedback
  • Search
  • Course enrollment
  • Online applications
  • Surveys

13. The Form Element

The <form> element is used to create an HTML form.

Syntax

<form>

Form elements

</form>

14. Basic Form Example

<form>

<label>Name:</label>

<input type="text">

<br>

<label>Email:</label>

<input type="email">

<br>

<input type="submit" value="Submit">

</form>

15. The Label Element

The <label> element provides a description for an input field.

Example

<label>Student Name:</label>

<input type="text">

Labels make forms easier to understand and improve accessibility.

16. The Input Element

The <input> element is one of the most commonly used form elements.

It allows users to enter or select information.

Basic Syntax

<input type="text">

17. Text Input

The type="text" input is used to enter normal text.

Example

<label>Name:</label>
<input type="text">

18. Email Input

The type="email" input is used to enter an email address.

Example

<label>Email:</label>
<input type="email">

Browsers can perform basic validation for email input.

19. Password Input

The type="password" input hides the characters entered by the user.

Example

<label>Password:</label>
<input type="password">

20. Number Input

The type="number" input is used to enter numeric values.

Example

<label>Age:</label>
<input type="number">

21. Date Input

The type="date" input allows the user to select a date.

Example

<label>Date of Birth:</label>
<input type="date">

22. Radio Buttons

Radio buttons allow the user to select one option from a group of options.

Example

<input type="radio" name="gender" value="male">
<label>Male</label>

<input type="radio" name="gender" value="female">
<label>Female</label>

The same name value groups the radio buttons together.

23. Checkboxes

Checkboxes allow users to select one or more options.

Example

<input type="checkbox" name="course" value="html">
<label>HTML</label>

<input type="checkbox" name="course" value="css">
<label>CSS</label>

<input type="checkbox" name="course" value="javascript">
<label>JavaScript</label>

24. Submit Button

The type="submit" input creates a button used to submit the form.

Example

<input type="submit" value="Register">

25. Reset Button

The type="reset" input clears the form fields and restores their initial values.

Example

<input type="reset" value="Reset">

26. Button Element

The <button> element is used to create a clickable button.

Example

<button>Submit</button>

27. Textarea

The <textarea> element is used when the user needs to enter multiple lines of text.

Example

<label>Address:</label>

<textarea rows="5" cols="30"></textarea>

28. Select Dropdown

The <select> element creates a dropdown list.

The <option> element defines each option.

Example

<label>Select Course:</label>

<select>

<option>HTML</option>
<option>CSS</option>
<option>JavaScript</option>
<option>PHP</option>

</select>

29. The Name Attribute

The name attribute gives a name to form data.

Example

<input type="text" name="username">

The name attribute is especially important when form data is sent to a server.

30. The Value Attribute

The value attribute specifies the value associated with an input element.

Example

<input type="text" value="Sejal">

31. Placeholder Attribute

The placeholder attribute displays a temporary hint inside an input field.

Example

<input type="text" placeholder="Enter your name">

32. Required Attribute

The required attribute makes a form field mandatory.

Example

<input type="email" required>

The user cannot submit the form normally without entering the required information.

33. Min and Max Attributes

The min and max attributes can be used with appropriate input types such as number.

Example

<input type="number" min="1" max="100">

34. The Action Attribute

The action attribute specifies where the form data should be sent after submission.

Example

<form action="register.php">

<input type="text" name="username">

<input type="submit" value="Register">

</form>

In this example, the form data is sent to register.php.

35. The Method Attribute

The method attribute specifies how the form data is sent.

The two commonly used methods are:

  • GET
  • POST

36. GET Method

The GET method sends form data through the URL.

Example

<form action="search.php" method="get">

<input type="text" name="search">

<input type="submit" value="Search">

</form>

GET is commonly used for searches and requests where the data can appear in the URL.

37. POST Method

The POST method sends form data in the HTTP request body rather than putting the submitted values in the URL.

Example

<form action="register.php" method="post">

<input type="text" name="username">

<input type="email" name="email">

<input type="submit" value="Register">

</form>

POST is commonly used for submitting registration and other data to a server.

38. GET vs POST

GET POST
Data is included in the URL. Data is sent in the request body.
Useful for searches and retrieving data. Commonly used for submitting data.
Not suitable for sensitive information. Better suited for sensitive form submissions, though HTTPS and server-side security are still required.

39. Complete Registration Form

The following is an example of a student registration form for an online academy.

<!DOCTYPE html>
<html>

<head>
<title>Student Registration</title>
</head>

<body>

<h1>Student Registration Form</h1>

<form action="register.php" method="post">

<label>Full Name:</label>
<input type="text" name="fullname" placeholder="Enter your full name" required>

<br>
<br>

<label>Email:</label>
<input type="email" name="email" placeholder="Enter your email" required>

<br>
<br>

<label>Password:</label>
<input type="password" name="password" required>

<br>
<br>

<label>Date of Birth:</label>
<input type="date" name="dob">

<br>
<br>

<label>Gender:</label>

<input type="radio" name="gender" value="male">
<label>Male</label>

<input type="radio" name="gender" value="female">
<label>Female</label>

<br>
<br>

<label>Select Course:</label>

<select name="course">

<option>HTML</option>
<option>CSS</option>
<option>JavaScript</option>
<option>PHP</option>

</select>

<br>
<br>

<label>Address:</label>

<br>

<textarea name="address" rows="5" cols="30"></textarea>

<br>
<br>

<input type="checkbox" name="terms" required>

<label>I agree to the terms and conditions.</label>

<br>
<br>

<input type="submit" value="Register">

<input type="reset" value="Reset">

</form>

</body>

</html>

40. Form Input Types

Input Type Purpose
text Normal text input
email Email address
password Password input
number Numeric input
date Date selection
radio Select one option from a group
checkbox Select one or more options
submit Submit the form
reset Reset the form
file Select a file
hidden Stores data that is not displayed to the user

41. Important Form Attributes

Attribute Purpose
action Specifies where form data is sent
method Specifies how form data is sent
name Identifies form data
value Specifies the value of an input
placeholder Displays a hint inside an input
required Makes an input mandatory
min Specifies minimum value
max Specifies maximum value
type Specifies the type of input

42. Important HTML Table Tags

Tag Purpose
<table> Creates a table
<tr> Creates a row
<th> Creates a heading cell
<td> Creates a data cell
<caption> Creates a table title
<thead> Groups table header rows
<tbody> Groups table body rows
<tfoot> Groups table footer rows

43. Important Points to Remember

  1. The <table> tag creates an HTML table.
  2. The <tr> tag creates a table row.
  3. The <th> tag creates a table heading.
  4. The <td> tag creates a table data cell.
  5. The colspan attribute combines columns.
  6. The rowspan attribute combines rows.
  7. The <form> tag creates an HTML form.
  8. The <label> tag describes form controls.
  9. The <input> tag creates input fields.
  10. The <textarea> tag creates a multi-line input area.
  11. The <select> tag creates a dropdown list.
  12. The <option> tag creates options inside a dropdown.
  13. The required attribute makes a field mandatory.
  14. The placeholder attribute displays a hint inside an input.
  15. The action attribute specifies where form data is sent.
  16. The method attribute specifies how form data is submitted.
  17. GET places submitted values in the URL.
  18. POST sends submitted values in the request body.
  19. HTML forms are commonly used for registration, login and contact pages.

Lesson Summary

In this lesson, you learned how to create HTML tables using rows, headings and data cells. You also learned how to create HTML forms using text fields, email fields, password fields, radio buttons, checkboxes, dropdowns, textareas and buttons.

You also learned important form attributes such as action, method, name, value, placeholder and required.
