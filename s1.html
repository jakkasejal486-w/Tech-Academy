SQL Lesson 1: SQL Basics and Database Fundamentals

1. Introduction to SQL

SQL stands for Structured Query Language.

SQL is a language used to communicate with relational databases.

It is used to create databases, create tables, store data, retrieve data, modify data and delete data.

SQL is widely used in websites, applications, banking systems, educational systems and business applications.

2. What is a Database?

A database is an organized collection of data that can be stored, managed and accessed easily.

For example, an online learning academy can store information about students, courses, registrations and results in a database.

Example

Student ID Name Email Course
101 Sejal sejal@example.com HTML
102 Rahul rahul@example.com CSS
103 Priya priya@example.com SQL

3. What is a Database Management System?

A Database Management System, or DBMS, is software used to create, manage and control databases.

It allows users and applications to store and retrieve data efficiently.

Examples of DBMS

  • MySQL
  • MariaDB
  • Oracle Database
  • Microsoft SQL Server
  • PostgreSQL

4. What is MySQL?

MySQL is a popular relational database management system that uses SQL.

It is commonly used for web applications and can be used with technologies such as PHP, JavaScript, Python and other programming languages.

Your Online Tech Learning Academy project can use MySQL or MariaDB to store student and course information.

5. SQL and MySQL Difference

SQL MySQL
SQL is a query language. MySQL is a database management system.
SQL is used to communicate with databases. MySQL stores and manages databases.
SQL provides commands such as SELECT and INSERT. MySQL executes SQL commands.

6. Relational Database

A relational database stores data in tables.

Tables contain rows and columns.

Different tables can also be connected using relationships.

Example

A learning academy database might contain these tables:

  • students
  • courses
  • enrollments
  • assignments
  • results

7. What is a Table?

A table is used to store related data in a database.

A table consists of rows and columns.

Example

id name email
1 Sejal sejal@example.com
2 Amit amit@example.com

8. Rows

A row represents one complete record in a table.

For example, one row in a students table can represent one student.

Example

1 | Sejal | sejal@example.com

9. Columns

A column represents a particular type of information stored in a table.

For example, a students table can contain columns such as id, name and email.

Example

id
name
email
phone

10. Creating a Database

The CREATE DATABASE command is used to create a new database.

Syntax

CREATE DATABASE database_name;

Example

CREATE DATABASE tech_learning_academy;

This creates a database named tech_learning_academy.

11. Showing Databases

The SHOW DATABASES command displays the databases available in the database server.

Example

SHOW DATABASES;

12. Selecting a Database

The USE command selects a database that you want to work with.

Syntax

USE database_name;

Example

USE tech_learning_academy;

13. Creating a Table

The CREATE TABLE command is used to create a new table inside a database.

Syntax

CREATE TABLE table_name(
column1 datatype,
column2 datatype,
column3 datatype
);

14. Creating a Students Table

For your project, a students table can be created like this:

CREATE TABLE students(
id INT,
name VARCHAR(100),
email VARCHAR(100),
phone VARCHAR(15)
);

15. SQL Data Types

Data types specify what type of data a column can store.

Data Type Purpose
INT Stores whole numbers.
VARCHAR Stores variable-length text.
CHAR Stores fixed-length text.
DATE Stores dates.
TIME Stores time values.
DECIMAL Stores decimal numbers.
BOOLEAN Stores true or false values.

16. INT Data Type

The INT data type is used to store whole numbers.

Example

id INT

17. VARCHAR Data Type

The VARCHAR data type is used to store text with a specified maximum length.

Example

name VARCHAR(100)

This allows the name column to store text up to the specified length.

18. DATE Data Type

The DATE data type is used to store dates.

Example

birth_date DATE

19. Creating a Complete Course Table

CREATE TABLE courses(
course_id INT,
course_name VARCHAR(100),
duration VARCHAR(50),
level VARCHAR(50)
);

20. Viewing Tables

The SHOW TABLES command displays all tables in the selected database.

Example

SHOW TABLES;

21. Viewing Table Structure

The DESCRIBE command can be used to view the structure of a table.

Example

DESCRIBE students;

It shows information such as column names, data types and other properties.

22. Inserting Data

The INSERT INTO command is used to add new records to a table.

Syntax

INSERT INTO table_name(column1,column2,column3)
VALUES(value1,value2,value3);

23. Inserting Student Data

INSERT INTO students(id,name,email,phone)
VALUES(1,'Sejal','sejal@example.com','9876543210');

24. Inserting Multiple Records

Multiple records can be inserted using a single INSERT statement.

INSERT INTO students(id,name,email,phone)
VALUES
(1,'Sejal','sejal@example.com','9876543210'),
(2,'Rahul','rahul@example.com','9876543211'),
(3,'Priya','priya@example.com','9876543212');

25. Selecting Data

The SELECT command is used to retrieve data from a table.

Syntax

SELECT column_name
FROM table_name;

26. Selecting All Data

The * symbol represents all columns.

Example

SELECT * FROM students;

This displays all columns and all records from the students table.

27. Selecting Specific Columns

You can select only the columns you need.

Example

SELECT name,email
FROM students;

28. Updating Data

The UPDATE command is used to modify existing records.

Syntax

UPDATE table_name
SET column_name=value
WHERE condition;

Example

UPDATE students
SET email='newemail@example.com'
WHERE id=1;

29. Deleting Data

The DELETE command is used to remove records from a table.

Example

DELETE FROM students
WHERE id=3;

The WHERE condition is important because it specifies which record should be deleted.

30. SQL Comments

Comments are used to explain SQL code and are ignored when the SQL statement is executed.

Single-Line Comment

-- This is a SQL comment

Example

-- Display all students

SELECT * FROM students;

31. SQL Operators

SQL operators are used to perform comparisons and logical operations.

Operator Meaning
= Equal to
!= Not equal to
> Greater than
< Less than
>= Greater than or equal to
<= Less than or equal to

32. WHERE Clause

The WHERE clause is used to filter records according to a condition.

Example

SELECT *
FROM students
WHERE id=1;

33. AND Operator

The AND operator is used when multiple conditions must be true.

Example

SELECT *
FROM students
WHERE id=1 AND name='Sejal';

34. OR Operator

The OR operator returns records when at least one condition is true.

Example

SELECT *
FROM students
WHERE name='Sejal' OR name='Priya';

35. NOT Operator

The NOT operator is used to reverse a condition.

Example

SELECT *
FROM students
WHERE NOT name='Sejal';

36. ORDER BY

The ORDER BY clause is used to sort query results.

Ascending Order

SELECT *
FROM students
ORDER BY name ASC;

Descending Order

SELECT *
FROM students
ORDER BY name DESC;

37. SQL NULL Value

NULL represents a missing or unknown value.

NULL is different from zero and an empty string.

Example

SELECT *
FROM students
WHERE email IS NULL;

  6. A column represents a particular type of data.
  7. MySQL and MariaDB are database management systems that support SQL.
  8. CREATE DATABASE creates a database.
  9. USE selects a database.
  10. CREATE TABLE creates a table.
  11. INSERT INTO adds data.
  12. SELECT retrieves data.
  13. UPDATE modifies existing data.
  14. DELETE removes data.
  15. WHERE filters records.
  16. ORDER BY sorts records.
  17. SQL data types define the type of information a column can store.
