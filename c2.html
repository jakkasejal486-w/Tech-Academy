CSS Lesson 2: Colors, Fonts and Text Styling

1. Introduction

CSS provides many properties for controlling the appearance of text and backgrounds on a webpage.

Colors, fonts and text styling are important parts of webpage design because they make content easier to read and visually attractive.

In this lesson, we will learn how to use CSS colors, background colors, fonts, text alignment, text decoration, text transformation, spacing and other text-related properties.

2. CSS Color Property

The color property is used to change the color of text.

Syntax

selector{
color:value;
}

Example

h1{
color:#40E0D0;
}

This changes the text color of the heading.

3. Color Names

CSS provides predefined color names that can be used directly as values.

Example

h1{
color:red;
}

p{
color:white;
}

body{
background-color:black;
}

4. Hexadecimal Colors

Hexadecimal colors are represented using a hash symbol followed by six hexadecimal characters.

Syntax

#RRGGBB

The first two characters represent red, the next two represent green and the last two represent blue.

Example

h1{
color:#40E0D0;
}

5. Common Hexadecimal Colors

Color Hex Code
Black #000000
White #FFFFFF
Red #FF0000
Green #008000
Blue #0000FF
Yellow #FFFF00
Turquoise #40E0D0
Purple #800080

6. RGB Colors

RGB stands for Red, Green and Blue.

The RGB color function uses three values representing the amount of red, green and blue.

Syntax

rgb(red,green,blue)

Example

h1{
color:rgb(64,224,208);
}

7. RGBA Colors

RGBA is an extension of RGB that includes an alpha value for controlling transparency.

Syntax

rgba(red,green,blue,alpha)

Example

div{
background-color:rgba(64,224,208,0.5);
}

The alpha value can range from 0 to 1.

0 means completely transparent and 1 means completely opaque.

8. HSL Colors

HSL stands for Hue, Saturation and Lightness.

Syntax

hsl(hue,saturation,lightness)

Example

h1{
color:hsl(174,72%,56%);
}

9. Background Color

The background-color property is used to set the background color of an element.

Example

body{
background-color:black;
}

nav{
background-color:#1e3a5f;
}

10. Background Image

The background-image property is used to set an image as the background of an element.

Example

body{
background-image:url("background.jpg");
}

11. Background Size

The background-size property controls the size of a background image.

Example

body{
background-size:cover;
}

The cover value makes the background image cover the available area.

12. Background Repeat

The background-repeat property controls whether a background image is repeated.

Example

body{
background-repeat:no-repeat;
}

13. Background Position

The background-position property controls the position of a background image.

Example

body{
background-position:center;
}

14. Font Family

The font-family property specifies the font used for text.

Example

body{
font-family:Arial,sans-serif;
}

15. Common Font Families

Font Example
Arial font-family:Arial;
Verdana font-family:Verdana;
Georgia font-family:Georgia;
Times New Roman font-family:"Times New Roman";
Courier New font-family:"Courier New";

16. Font Size

The font-size property controls the size of text.

Example

h1{
font-size:36px;
}

p{
font-size:18px;
}

17. Font Weight

The font-weight property controls the thickness of text.

Example

h1{
font-weight:bold;
}

Common values include normal, bold and numerical values such as 400 and 700.

18. Font Style

The font-style property controls whether text is normal, italic or oblique.

Example

p{
font-style:italic;
}

19. Font Variant

The font-variant property can be used to display text in a small-caps style.

Example

p{
font-variant:small-caps;
}

20. Text Alignment

The text-align property controls the horizontal alignment of text.

Example

h1{
text-align:center;
}

p{
text-align:left;
}

Common values are left, right, center and justify.

21. Text Decoration

The text-decoration property adds or removes decorations from text.

Example

h2{
text-decoration:underline;
}

a{
text-decoration:none;
}

22. Text Transformation

The text-transform property controls the capitalization of text.

Example

h1{
text-transform:uppercase;
}

Common values include uppercase, lowercase and capitalize.

23. Text Indentation

The text-indent property specifies the indentation of the first line of text.

Example

p{
text-indent:40px;
}

24. Letter Spacing

The letter-spacing property controls the space between individual characters.

Example

h1{
letter-spacing:3px;
}

25. Word Spacing

The word-spacing property controls the space between words.

Example

p{
word-spacing:5px;
}

26. Line Height

The line-height property controls the vertical space between lines of text.

Example

p{
line-height:1.8;
}

Line height is useful for improving the readability of paragraphs.

27. Text Shadow

The text-shadow property adds a shadow effect to text.

Syntax

text-shadow:horizontal vertical blur color;

Example

h1{
text-shadow:2px 2px 5px black;
}

28. Text Direction

The direction property specifies the direction in which text is displayed.

Example

p{
direction:ltr;
}

ltr means left-to-right and rtl means right-to-left.

29. White Space

The white-space property controls how white space inside an element is handled.

Example

p{
white-space:nowrap;
}

30. Text Overflow

The text-overflow property controls how text that cannot fit inside an element is displayed.

Example

div{
white-space:nowrap;
overflow:hidden;
text-overflow:ellipsis;
}

The ellipsis value can display three dots when text is cut off.

31. Opacity

The opacity property controls the transparency of an element.

Example

p{
opacity:0.5;
}

The value ranges from 0 to 1.

33. CSS Background Properties

Property Purpose
background-color Sets background color
background-image Sets a background image
background-size Controls background image size
background-repeat Controls image repetition
background-position Controls image position
opacity Controls transparency

34. Styling a Heading

The following example demonstrates multiple text properties together.

h1{
color:#40E0D0;
font-family:Arial,sans-serif;
font-size:36px;
font-weight:bold;
font-style:normal;
text-align:center;
text-decoration:underline;
text-transform:uppercase;
letter-spacing:2px;
text-shadow:2px 2px 5px black;
}

35. Styling a Paragraph

p{
color:white;
font-family:Arial,sans-serif;
font-size:18px;
font-weight:normal;
line-height:1.8;
text-align:justify;
letter-spacing:1px;
word-spacing:3px;
}

36. Styling Links

CSS can be used to style hyperlinks.

a{
color:#40E0D0;
text-decoration:none;
font-weight:bold;
}

a:hover{
color:white;
}

37. Styling Navigation Links

This is useful for your Online Tech Learning Academy navigation bar.

nav a{
color:#40E0D0;
text-decoration:none;
font-size:15px;
font-weight:bold;
}

nav a:hover{
color:white;
}

38. Complete Example

The following example combines colors, fonts and text properties.

<!DOCTYPE html>

<html>

<head>

<title>CSS Text Styling</title>

<style>

body{
background-color:black;
font-family:Arial,sans-serif;
}

h1{
color:#40E0D0;
text-align:center;
font-size:36px;
font-weight:bold;
text-decoration:underline;
text-transform:uppercase;
letter-spacing:2px;
}

p{
color:white;
font-size:18px;
line-height:1.8;
text-align:justify;
}

a{
color:#40E0D0;
text-decoration:none;
font-weight:bold;
}

a:hover{
color:white;
}

</style>

</head>

<body>

<h1>
Online Tech Learning Academy
</h1>

<p>
Learn CSS and create attractive webpages.
</p>

<a href="#">
Learn More
</a>

</body>

</html>

39. CSS Font Shorthand

CSS allows multiple font properties to be written using the font shorthand property.

Example

p{
font:italic bold 18px Arial;
}

This can specify the font style, weight, size and family in one declaration.

40. Important Points to Remember

  1. The color property changes the color of text.
  2. The background-color property changes the background color.
  3. CSS supports named colors, hexadecimal colors, RGB, RGBA and HSL colors.
  4. The font-family property specifies the font.
  5. The font-size property controls text size.
  6. The font-weight property controls text thickness.
  7. The font-style property can make text italic.
  8. The text-align property controls horizontal alignment.
  9. The text-decoration property adds or removes text decoration.
  10. The text-transform property controls capitalization.
  11. The letter-spacing property controls space between characters.
  12. The word-spacing property controls space between words.
  13. The line-height property controls the distance between lines.
  14. The text-shadow property adds a shadow to text.
  15. The opacity property controls transparency.
  16. Background properties can be used to create attractive webpage designs.

Lesson Summary

In this lesson, you learned how CSS can be used to style colors, backgrounds, fonts and text.

You learned about named colors, hexadecimal colors, RGB, RGBA and HSL.

You also learned important font properties such as font-family, font-size, font-weight and font-style.

Important text properties such as text-align, text-decoration, text-transform, letter-spacing, word-spacing, line-height and text-shadow were also covered.

These properties are very useful when designing the pages of your Online Tech Learning Academy project.
