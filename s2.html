SQL Lesson 2: Data Manipulation and Queries

1. Introduction to Data Manipulation

Data Manipulation means adding, retrieving, changing and removing data from a database.

SQL provides different commands to perform these operations.

The four most important data manipulation commands are:

  • INSERT
  • SELECT
  • UPDATE
  • DELETE

These commands are commonly called DML commands.

2. What is DML?

DML stands for Data Manipulation Language.

DML contains SQL commands that are used to work with the data stored inside database tables.

Command Purpose
INSERT Adds new records.
SELECT Retrieves records.
UPDATE Changes existing records.
DELETE Removes records.

3. Creating a Database for Practice

We will use a simple student database for the examples in this lesson.

CREATE DATABASE tech_learning_academy;

USE tech_learning_academy;

4. Creating a Students Table

CREATE TABLE students(
id INT,
name VARCHAR(100),
email VARCHAR(100),
course VARCHAR(100),
age INT
);

5. INSERT Command

The INSERT INTO command is used to add new records to a table.

Syntax

INSERT INTO table_name(column1,column2,column3)
VALUES(value1,value2,value3);

6. Inserting One Record

INSERT INTO students(id,name,email,course,age)
VALUES(1,'Sejal','sejal@example.com','HTML',20);

This statement adds one student record to the students table.

7. Inserting Multiple Records

Multiple records can be inserted using one INSERT statement.

INSERT INTO students(id,name,email,course,age)
VALUES
(1,'Sejal','sejal@example.com','HTML',20),
(2,'Rahul','rahul@example.com','CSS',21),
(3,'Priya','priya@example.com','SQL',20),
(4,'Amit','amit@example.com','JavaScript',22);

8. SELECT Command

The SELECT command is used to retrieve data from a database table.

Syntax

SELECT column_name
FROM table_name;

9. Selecting All Columns

The asterisk symbol * represents all columns.

SELECT * FROM students;

This displays all records and all columns from the students table.

10. Selecting Specific Columns

We can select only the columns that we need.

SELECT name,email
FROM students;

11. Selecting One Column

SELECT name
FROM students;

This displays only the names of students.

12. WHERE Clause

The WHERE clause is used to filter records according to a condition.

Syntax

SELECT *
FROM table_name
WHERE condition;

Example

SELECT *
FROM students
WHERE course='HTML';

This returns students whose course is HTML.

13. WHERE with Numbers

Conditions can also be applied to numeric columns.

SELECT *
FROM students
WHERE age=20;

14. Comparison Operators

Operator Meaning
= Equal to
!= Not equal to
> Greater than
< Less than
>= Greater than or equal to
<= Less than or equal to

15. Greater Than

SELECT *
FROM students
WHERE age>20;

16. Less Than

SELECT *
FROM students
WHERE age<21;

17. Not Equal To

SELECT *
FROM students
WHERE course!='HTML';

18. AND Operator

The AND operator is used when all specified conditions must be true.

Example

SELECT *
FROM students
WHERE age=20 AND course='HTML';

19. OR Operator

The OR operator is used when at least one condition must be true.

Example

SELECT *
FROM students
WHERE course='HTML' OR course='CSS';

20. NOT Operator

The NOT operator reverses a condition.

Example

SELECT *
FROM students
WHERE NOT course='HTML';

21. ORDER BY

The ORDER BY clause is used to sort records.

Ascending Order

SELECT *
FROM students
ORDER BY name ASC;

Descending Order

SELECT *
FROM students
ORDER BY name DESC;

22. ASC and DESC

Keyword Meaning
ASC Ascending order.
DESC Descending order.

ASC is the default sorting direction when no direction is specified.

23. DISTINCT

The DISTINCT keyword is used to remove duplicate values from the result.

Example

SELECT DISTINCT course
FROM students;

This displays each course only once.

24. LIKE Operator

The LIKE operator is used to search for a specified pattern in text.

Example

SELECT *
FROM students
WHERE name LIKE 'S%';

This finds names that start with the letter S.

25. Percentage Wildcard

The % wildcard represents zero or more characters.

Starts With

SELECT *
FROM students
WHERE name LIKE 'S%';

Ends With

SELECT *
FROM students
WHERE name LIKE '%a';

Contains

SELECT *
FROM students
WHERE name LIKE '%e%';

26. Underscore Wildcard

The underscore _ represents one single character.

Example

SELECT *
FROM students
WHERE name LIKE '_e%';

This searches for names where the second character is e.

27. IN Operator

The IN operator allows multiple possible values to be specified in a WHERE condition.

Example

SELECT *
FROM students
WHERE course IN('HTML','CSS','SQL');

28. NOT IN

NOT IN returns records whose values are not present in the specified list.

Example

SELECT *
FROM students
WHERE course NOT IN('HTML','CSS');

29. BETWEEN Operator

The BETWEEN operator selects values within a specified range.

Example

SELECT *
FROM students
WHERE age BETWEEN 20 AND 22;

30. NOT BETWEEN

NOT BETWEEN selects values outside the specified range.

Example

SELECT *
FROM students
WHERE age NOT BETWEEN 20 AND 22;

31. UPDATE Command

The UPDATE command is used to modify existing records.

Syntax

UPDATE table_name
SET column_name=value
WHERE condition;

32. Updating One Record

UPDATE students
SET course='CSS'
WHERE id=1;

This changes the course of the student whose id is 1.

33. Updating Multiple Columns

Multiple columns can be updated in the same statement.

UPDATE students
SET name='Sejal Jakka',
email='sejaljakka@example.com'
WHERE id=1;

34. Importance of WHERE with UPDATE

Always use a suitable WHERE condition when you want to update specific records.

Without a WHERE condition, the UPDATE statement can change every record in the table.

Example

UPDATE students
SET course='SQL';

This changes the course value for all records.

35. DELETE Command

The DELETE command is used to remove records from a table.

Syntax

DELETE FROM table_name
WHERE condition;

36. Deleting One Record

DELETE FROM students
WHERE id=4;

This deletes the student whose id is 4.

37. Importance of WHERE with DELETE

Be careful when using DELETE.

If the WHERE clause is not included, all records in the table may be deleted.

Example

DELETE FROM students;

This removes all records from the students table while leaving the table itself available.

38. LIMIT

The LIMIT clause is commonly used to restrict the number of records returned by a query.

Example

SELECT *
FROM students
LIMIT 2;

This returns up to two records.

39. Combining SQL Clauses

Multiple SQL features can be used together.

Example

SELECT name,email,course
FROM students
WHERE age>19
ORDER BY name ASC
LIMIT 3;

40. Practical Example for Online Tech Learning Academy

Suppose your academy has the following student records:

ID Name Course Age

Find all SQL students

SELECT *
FROM students
WHERE course='SQL';

FROM students

SELECT *
FROM students

Find HTML and CSS students

FROM students

44. Important Points to Remember

  1. DML stands for Data Manipulation Language.
  2. INSERT is used to add records.
  3. SELECT is used to retrieve records.
  4. UPDATE is used to modify records.
  5. DELETE is used to remove records.
  6. WHERE is used to filter records.
  7. ORDER BY is used to sort records.
  8. ASC sorts values in ascending order.
  9. DESC sorts values in descending order.
  10. DISTINCT removes duplicate results.
  11. LIKE is useful for pattern searching.
  12. The % wildcard represents zero or more characters.
  13. The _ wildcard represents one character.
  14. IN allows multiple possible values.
  15. BETWEEN is used for ranges.
  16. LIMIT restricts the number of returned records.
  17. Be careful when using UPDATE without WHERE.
  18. Be careful when using DELETE without WHERE.
  19. These commands are important for managing student and course data in your project.
