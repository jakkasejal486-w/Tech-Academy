SQL Lesson 4: Functions, GROUP BY and HAVING

1. Introduction to SQL Functions

SQL functions are built-in operations that perform calculations or process data and return a result.

Functions are useful when we need to calculate totals, averages, counts and other information from database records.

For example, an online learning academy can use SQL functions to find the number of students enrolled in each course or calculate the average marks of students.

2. Types of SQL Functions

SQL functions can be broadly divided into two categories:

  • Aggregate Functions
  • Scalar Functions

Aggregate functions work with multiple rows and return one result.

Scalar functions generally work with individual values and return a value for each row.

3. Aggregate Functions

Aggregate functions perform calculations on a group of rows.

Function Purpose
COUNT() Counts records.
SUM() Calculates the total.
AVG() Calculates the average.
MIN() Finds the smallest value.
MAX() Finds the largest value.

4. COUNT() Function

The COUNT() function is used to count records.

Example

SELECT COUNT(*)
FROM students;

This returns the total number of student records.

5. COUNT() with a Column

COUNT can also be used with a specific column.

SELECT COUNT(email)
FROM students;

This counts non-NULL values in the email column.

6. COUNT() with WHERE

We can count records that satisfy a particular condition.

SELECT COUNT(*)
FROM students
WHERE course='HTML';

This counts the students enrolled in HTML.

7. SUM() Function

The SUM() function calculates the total of numeric values.

Example

Suppose a results table contains marks.

SELECT SUM(marks)
FROM results;

This calculates the total marks.

8. SUM() with WHERE

SELECT SUM(marks)
FROM results
WHERE course_id=1;

This calculates the total marks for the specified course.

9. AVG() Function

The AVG() function calculates the average of numeric values.

Example

SELECT AVG(marks)
FROM results;

This calculates the average marks.

10. AVG() with WHERE

SELECT AVG(marks)
FROM results
WHERE course_id=1;

This calculates the average marks for the specified course.

11. MIN() Function

The MIN() function returns the smallest value.

Example

SELECT MIN(marks)
FROM results;

This finds the lowest marks.

12. MAX() Function

The MAX() function returns the largest value.

Example

SELECT MAX(marks)
FROM results;

This finds the highest marks.

13. Using Multiple Aggregate Functions

Multiple functions can be used in the same query.

SELECT
COUNT(*) AS total_students,
AVG(marks) AS average_marks,
MIN(marks) AS lowest_marks,
MAX(marks) AS highest_marks
FROM results;

14. AS Keyword

The AS keyword is used to create an alias for a column or calculated result.

Example

SELECT COUNT(*) AS total_students
FROM students;

Instead of displaying the calculation using its original expression, the result is displayed with the name total_students.

15. Creating a Results Table

For practice, we can create a results table for the academy.

CREATE TABLE results(
result_id INT PRIMARY KEY AUTO_INCREMENT,
student_id INT,
course_id INT,
marks INT
);

16. Adding Result Data

INSERT INTO results(student_id,course_id,marks)
VALUES
(1,1,85),
(2,1,75),
(3,1,90),
(1,2,88),
(2,2,80),
(3,2,95);

17. Finding Total Number of Results

SELECT COUNT(*) AS total_results
FROM results;

18. Finding Total Marks

SELECT SUM(marks) AS total_marks
FROM results;

19. Finding Average Marks

SELECT AVG(marks) AS average_marks
FROM results;

20. Finding Lowest Marks

SELECT MIN(marks) AS lowest_marks
FROM results;

21. Finding Highest Marks

SELECT MAX(marks) AS highest_marks
FROM results;

22. GROUP BY

The GROUP BY clause is used to group rows that have the same values in specified columns.

It is commonly used with aggregate functions.

Example

SELECT course_id,COUNT(*) AS total_students
FROM enrollments
GROUP BY course_id;

This groups enrollment records according to course ID and counts the records in each group.

23. GROUP BY with AVG()

We can calculate the average marks for each course.

SELECT course_id,AVG(marks) AS average_marks
FROM results
GROUP BY course_id;

24. GROUP BY with SUM()

SELECT course_id,SUM(marks) AS total_marks
FROM results
GROUP BY course_id;

25. GROUP BY with MIN()

SELECT course_id,MIN(marks) AS lowest_marks
FROM results
GROUP BY course_id;

26. GROUP BY with MAX()

SELECT course_id,MAX(marks) AS highest_marks
FROM results
GROUP BY course_id;

27. GROUP BY Example

course_id marks
1 85
1 75
1 90
2 88
2 80
2 95

Using GROUP BY course_id allows the results to be divided into separate groups for course 1 and course 2.

28. HAVING Clause

The HAVING clause is used to filter grouped results.

It is commonly used with GROUP BY and aggregate functions.

Example

SELECT course_id,COUNT(*) AS total_students
FROM enrollments
GROUP BY course_id
HAVING COUNT(*)>2;

This returns only courses having more than two enrollment records.

29. WHERE vs HAVING

WHERE HAVING
Filters individual rows. Filters groups.
Usually used before GROUP BY. Usually used after GROUP BY.
Can filter normal column values. Commonly filters aggregate results.

30. WHERE with GROUP BY

WHERE can be used before GROUP BY to filter records before grouping.

SELECT course_id,AVG(marks) AS average_marks
FROM results
WHERE marks>50
GROUP BY course_id;

31. HAVING with GROUP BY

HAVING filters the groups after they have been created.

SELECT course_id,AVG(marks) AS average_marks
FROM results
GROUP BY course_id
HAVING AVG(marks)>80;

This displays courses whose average marks are greater than 80.

32. GROUP BY with ORDER BY

GROUP BY and ORDER BY can be used together.

SELECT course_id,AVG(marks) AS average_marks
FROM results
GROUP BY course_id
ORDER BY average_marks DESC;

This displays courses from the highest average marks to the lowest.

33. Complete Query Example

SELECT course_id,
COUNT(*) AS total_results,
AVG(marks) AS average_marks,
MIN(marks) AS lowest_marks,
MAX(marks) AS highest_marks
FROM results
GROUP BY course_id
HAVING AVG(marks)>70
ORDER BY average_marks DESC;

34. SQL String Functions

SQL also provides functions for working with text.

Function Purpose
UPPER() Converts text to uppercase.
LOWER() Converts text to lowercase.
LENGTH() Returns the length of text.

35. UPPER() Function

The UPPER() function converts text to uppercase.

SELECT UPPER(name)
FROM students;

36. LOWER() Function

The LOWER() function converts text to lowercase.

SELECT LOWER(name)
FROM students;

37. LENGTH() Function

The LENGTH() function returns the number of characters in a string.

SELECT name,LENGTH(name) AS name_length
FROM students;

38. Numeric Functions

SQL also provides functions for working with numbers.

Function Purpose
ROUND() Rounds a number.
CEIL() Rounds a number upward.
FLOOR() Rounds a number downward.

39. ROUND() Function

The ROUND() function rounds a number to a specified number of decimal places.

SELECT ROUND(AVG(marks),2)
FROM results;

40. Complete Academy Example

Suppose your academy wants to display statistics about student results.

SELECT
course_id,
COUNT(*) AS number_of_students,
AVG(marks) AS average_marks,
MIN(marks) AS minimum_marks,
MAX(marks) AS maximum_marks
FROM results
GROUP BY course_id
ORDER BY average_marks DESC;

41. Important Aggregate Functions

Function Example Purpose
COUNT() COUNT(*) Counts records.

AVG() AVG(marks) Calculates average.
MIN() MIN(marks) Finds minimum value.
MAX() MAX(marks) Finds maximum value.

42. Important SQL Clauses

Clause Purpose
WHERE Filters rows.
GROUP BY Groups similar rows.
HAVING Filters groups.
ORDER BY Sorts results.

43. Important Points to Remember

  1. SQL functions perform calculations or process data.
  2. Aggregate functions work with multiple rows.
  3. COUNT() counts records.
  4. SUM() calculates a total.
  5. AVG() calculates an average.
  6. MIN() finds the smallest value.
  7. MAX() finds the largest value.
  8. GROUP BY groups records with similar values.
  9. GROUP BY is commonly used with aggregate functions.
  10. HAVING filters grouped results.
  11. WHERE filters individual rows.
  12. AS creates an alias for a column or result.
  13. ORDER BY can be used to sort grouped results.
  14. Aggregate functions are useful for reports and statistics.
  15. These concepts can be used to display student results and course statistics in your academy project.
