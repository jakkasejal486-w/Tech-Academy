HTML Lesson 2: Text Formatting, Lists, Links and Images

1. Introduction

In this lesson, we will learn how to format text, create different types of lists, create links and add images to an HTML webpage.

These elements are commonly used when designing real websites and are important for creating clear and organized webpage content.

2. HTML Text Formatting

HTML provides different tags for formatting and giving importance to text.

Some commonly used formatting tags are:

Tag Purpose
<b> Makes text bold
<strong> Shows important text
<i> Makes text italic
<em> Emphasizes text
<u> Underlines text
<mark> Highlights text
<small> Displays smaller text
<del> Shows deleted text
<ins> Shows inserted text
<sub> Creates subscript text
<sup> Creates superscript text

3. Bold Text

The <b> tag is used to make text bold.

Syntax

<b>This text is bold</b>

Example

<p>Welcome to <b>Online Tech Learning Academy</b>.</p>

Output:

Welcome to Online Tech Learning Academy.

4. Strong Text

The <strong> tag is used to indicate that the text is important.

Example

<p><strong>Important Notice</strong></p>

It normally appears bold in the browser.

The <strong> tag gives semantic meaning that the content is important.

5. Italic Text

The <i> tag is used to display text in italic style.

Example

<p>This is <i>italic text</i>.</p>

Output:

This is italic text.

6. Emphasized Text

The <em> tag is used to emphasize text.

Example

<p>You <em>must</em> complete this lesson.</p>

The text normally appears italic.

7. Underlined Text

The <u> tag is used to underline text.

Example

<p><u>HTML Course</u></p>

Output:

HTML Course

8. Highlighted Text

The <mark> tag is used to highlight text.

Example

<p>Learn <mark>HTML</mark> first.</p>

Output:

Learn HTML first.

9. Small Text

The <small> tag displays text smaller than the surrounding text.

Example

<p>This is normal text.</p>
<p><small>This is small text.</small></p>

Output:

This is normal text.

This is small text.

10. Deleted Text

The <del> tag represents text that has been deleted.

Example

<p>Price: <del>₹1000</del> ₹700</p>

Output:

Price: ₹1000 ₹700

11. Inserted Text

The <ins> tag represents text that has been inserted.

Example

<p>New price: <ins>₹700</ins></p>

Output:

New price: ₹700

12. Subscript Text

The <sub> tag is used to display text below the normal line.

Example

<p>H<sub>2</sub>O</p>

Output:

H2O

13. Superscript Text

The <sup> tag is used to display text above the normal line.

Example

<p>X<sup>2</sup></p>

Output:

X2

14. Combining Text Formatting Tags

Multiple formatting tags can be used together.

Example

<p>
<b><i>Welcome to HTML</i></b>
</p>

Different formatting elements can be nested inside each other.

15. HTML Lists

Lists are used to display related items in an organized way.

HTML mainly provides three types of lists:

  1. Unordered List
  2. Ordered List
  3. Description List

16. Unordered List

An unordered list displays items using bullets.

The unordered list uses the <ul> tag.

Each item is written using the <li> tag.

Syntax

<ul>
<li>HTML</li>
<li>CSS</li>
<li>JavaScript</li>
</ul>

Output

  • HTML
  • CSS
  • JavaScript

17. Ordered List

An ordered list displays items in a particular order using numbers by default.

The ordered list uses the <ol> tag.

Example

<ol>
<li>HTML</li>
<li>CSS</li>
<li>JavaScript</li>
</ol>

Output

  1. HTML
  2. CSS
  3. JavaScript

18. Ordered List with Different Numbering

The type attribute can be used to change the numbering style of an ordered list.

Uppercase Letters

<ol type="A">
<li>HTML</li>
<li>CSS</li>
<li>JavaScript</li>
</ol>

Lowercase Letters

<ol type="a">
<li>HTML</li>
<li>CSS</li>
<li>JavaScript</li>
</ol>

Roman Numbers

<ol type="I">
<li>HTML</li>
<li>CSS</li>
<li>JavaScript</li>
</ol>

19. Description List

A description list is used to display terms and their descriptions.

It uses:

  • <dl> for the description list.
  • <dt> for the term.
  • <dd> for the description.

Example

<dl>
<dt>HTML</dt>
<dd>Language used to structure webpages.</dd>

<dt>CSS</dt>
<dd>Language used to style webpages.</dd>
</dl>

20. Nested Lists

A list can contain another list inside it. This is called a nested list.

Example

<ul>
<li>Frontend
<ul>
<li>HTML</li>
<li>CSS</li>
<li>JavaScript</li>
</ul>
</li>

<li>Backend
<ul>
<li>PHP</li>
<li>MySQL</li>
</ul>
</li>
</ul>

21. HTML Links

Links are used to connect one webpage to another webpage or resource.

The <a> tag is used to create a hyperlink.

Syntax

<a href="URL">Link Text</a>

Example

<a href="https://www.google.com">Visit Google</a>

22. Linking Another HTML Page

HTML pages in the same project folder can be connected using their filenames.

Example

<a href="about.html">About Us</a>

When the user clicks the link, the browser opens about.html.

23. Opening a Link in a New Tab

The target="_blank" attribute can be used to open a link in a new browser tab.

Example

<a href="https://www.google.com" target="_blank">
Visit Google
</a>

24. Email Links

The mailto: scheme can be used to create a link that opens the user's email application.

Example

<a href="mailto:example@gmail.com">
Send Email
</a>

25. Telephone Links

The tel: scheme can be used to create a telephone link.

Example

<a href="tel:+911234567890">
Call Us
</a>

26. Images in HTML

Images make webpages more attractive and help users understand information visually.

The <img> tag is used to add an image to a webpage.

Syntax

<img src="image.jpg" alt="Description">

The <img> tag is a void element, so it does not require a closing tag.

27. The src Attribute

The src attribute specifies the location of the image.

Example

<img src="student.jpg">

If the image is stored in another folder:

<img src="images/student.jpg">

28. The alt Attribute

The alt attribute provides alternative text for an image.

Example

<img src="student.jpg" alt="Student learning HTML">

The alternative text is useful when an image cannot be displayed and also improves accessibility.

29. Image Width and Height

The width and height attributes can be used to specify the dimensions of an image.

Example

<img src="student.jpg"
width="300"
height="200"
alt="Student">

30. Image as a Link

An image can also be used as a clickable link by placing the <img> element inside an <a> element.

Example

<a href="https://www.google.com">
<img src="google.jpg" alt="Google">
</a>
