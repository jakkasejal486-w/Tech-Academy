SQL Lesson 5: JOINs

1. Introduction to SQL JOINs

SQL JOINs are used to combine data from two or more tables based on a related column.

In a database, information is usually stored in separate tables. JOINs allow us to retrieve related information from these tables together.

For example, in your Online Tech Learning Academy, student information can be stored in one table and course information can be stored in another table.

2. Why Do We Need JOINs?

Suppose we have two tables:

  • students table
  • courses table

The students table contains student information, while the courses table contains course information.

To display the student's name together with the course name, we need to combine the tables.

SQL JOINs are used for this purpose.

3. Types of SQL JOINs

JOIN Purpose
INNER JOIN Returns matching records from both tables.
LEFT JOIN Returns all records from the left table and matching records from the right table.
RIGHT JOIN Returns all records from the right table and matching records from the left table.
FULL OUTER JOIN Returns all records from both tables.
CROSS JOIN Returns every possible combination of rows.
SELF JOIN Joins a table with itself.

5. INNER JOIN

INNER JOIN returns only the records that have matching values in both tables.

It is one of the most commonly used JOINs.

Syntax

SELECT column1,column2
FROM table1
INNER JOIN table2
ON table1.column=table2.column;

6. INNER JOIN Example

SELECT students.name,courses.course_name
FROM students
INNER JOIN courses
ON students.course_id=courses.course_id;

The result will contain the student name and the corresponding course name.

7. INNER JOIN Result

name course_name
Sejal HTML
Rahul CSS
Priya SQL
Amit HTML

8. INNER JOIN with WHERE

JOIN can be combined with WHERE to filter the result.

SELECT students.name,courses.course_name
FROM students
INNER JOIN courses
ON students.course_id=courses.course_id
WHERE courses.course_name='HTML';

This displays students who are enrolled in the HTML course.

9. LEFT JOIN

LEFT JOIN returns all records from the left table and the matching records from the right table.

If there is no matching record in the right table, NULL values are returned.

Syntax

SELECT column1,column2
FROM table1
LEFT JOIN table2
ON table1.column=table2.column;

10. LEFT JOIN Example

SELECT students.name,courses.course_name
FROM students
LEFT JOIN courses
ON students.course_id=courses.course_id;

This displays all students, including students whose course does not have a matching record.

11. Why LEFT JOIN is Useful

  • It keeps every record from the first table.
  • It is useful when some records may not have related data.
  • Missing matching values appear as NULL.
  • It is useful for finding students who are not enrolled in a course.

12. Finding Students Without a Course

LEFT JOIN can be combined with IS NULL.

SELECT students.name
FROM students
LEFT JOIN courses
ON students.course_id=courses.course_id
WHERE courses.course_id IS NULL;

This can be used to find students whose course does not have a matching course record.

13. RIGHT JOIN

RIGHT JOIN returns all records from the right table and matching records from the left table.

Syntax

SELECT column1,column2
FROM table1
RIGHT JOIN table2
ON table1.column=table2.column;

14. RIGHT JOIN Example

SELECT students.name,courses.course_name
FROM students
RIGHT JOIN courses
ON students.course_id=courses.course_id;

This returns all courses and matching students.

15. FULL OUTER JOIN

FULL OUTER JOIN returns all records from both tables.

If a record does not have a matching record in the other table, NULL values are returned.

Syntax

SELECT column1,column2
FROM table1
FULL OUTER JOIN table2
ON table1.column=table2.column;

Note: MySQL does not provide a direct FULL OUTER JOIN syntax. In MySQL, similar results can commonly be produced using LEFT JOIN and RIGHT JOIN with UNION.

16. FULL OUTER JOIN in MySQL

SELECT students.name,courses.course_name
FROM students
LEFT JOIN courses
ON students.course_id=courses.course_id

UNION

SELECT students.name,courses.course_name
FROM students
RIGHT JOIN courses
ON students.course_id=courses.course_id;

17. CROSS JOIN

CROSS JOIN returns every possible combination of rows from two tables.

If the first table contains 3 rows and the second table contains 4 rows, the result can contain 12 combinations.

Syntax

SELECT students.name,courses.course_name
FROM students
CROSS JOIN courses;

18. SELF JOIN

A SELF JOIN is a JOIN where a table is joined with itself.

It is useful when records within the same table are related to each other.

Example

SELECT A.name AS student1,
B.name AS student2
FROM students A
JOIN students B
ON A.course_id=B.course_id
WHERE A.student_id<B.student_id;

This can display pairs of students who are enrolled in the same course.

19. JOIN with Three Tables

SQL allows us to join more than two tables.

For your academy project, we can have:

  • students
  • courses
  • enrollments

Example

SELECT students.name,courses.course_name
FROM students
INNER JOIN enrollments
ON students.student_id=enrollments.student_id
INNER JOIN courses
ON enrollments.course_id=courses.course_id;

20. JOIN with Three Tables Explained

The first JOIN connects students with enrollments.

The second JOIN connects enrollments with courses.

The final result can show which courses each student has enrolled in.

21. JOIN with Student and Course Information

SELECT
students.student_id,
students.name,
courses.course_name
FROM students
INNER JOIN enrollments
ON students.student_id=enrollments.student_id
INNER JOIN courses
ON enrollments.course_id=courses.course_id;

22. JOIN with WHERE

We can display students enrolled in a specific course.

SELECT
students.name,
courses.course_name
FROM students
INNER JOIN enrollments
ON students.student_id=enrollments.student_id
INNER JOIN courses
ON enrollments.course_id=courses.course_id
WHERE courses.course_name='SQL';

23. JOIN with ORDER BY

JOIN results can be sorted using ORDER BY.

SELECT
students.name,
courses.course_name
FROM students
INNER JOIN enrollments
ON students.student_id=enrollments.student_id
INNER JOIN courses
ON enrollments.course_id=courses.course_id
ORDER BY students.name ASC;

24. JOIN with GROUP BY

JOIN can also be combined with GROUP BY to calculate statistics.

For example, we can find the number of students in each course.

SELECT
courses.course_name,
COUNT(enrollments.student_id) AS total_students
FROM courses
LEFT JOIN enrollments
ON courses.course_id=enrollments.course_id
GROUP BY courses.course_id,courses.course_name;

25. JOIN with GROUP BY and HAVING

We can use HAVING to display courses with a particular number of students.

SELECT
courses.course_name,
COUNT(enrollments.student_id) AS total_students
FROM courses
LEFT JOIN enrollments
ON courses.course_id=enrollments.course_id
GROUP BY courses.course_id,courses.course_name
HAVING COUNT(enrollments.student_id)>1;

26. JOIN Conditions

The ON clause specifies how two tables are related.

ON students.course_id=courses.course_id

Here, the course_id column in the students table is matched with the course_id column in the courses table.

27. ON vs WHERE

ON WHERE
Defines how tables are joined. Filters the final result.
Used with JOIN. Used to apply conditions.
Specifies matching columns. Specifies filtering conditions.

28. Table Aliases

Aliases can make JOIN queries shorter and easier to read.

Example

SELECT s.name,c.course_name
FROM students AS s
INNER JOIN courses AS c
ON s.course_id=c.course_id;

29. JOIN Types Comparison

JOIN Type Returns
INNER JOIN Matching records from both tables.
LEFT JOIN All left records and matching right records.
RIGHT JOIN All right records and matching left records.
FULL OUTER JOIN All records from both tables.
CROSS JOIN All possible combinations.
SELF JOIN A table joined with itself.

30. Complete Academy Database Example

Students Table

CREATE TABLE students(
student_id INT PRIMARY KEY AUTO_INCREMENT,
name VARCHAR(100) NOT NULL,
email VARCHAR(100) UNIQUE NOT NULL
);

Courses Table

CREATE TABLE courses(
course_id INT PRIMARY KEY AUTO_INCREMENT,
course_name VARCHAR(100) NOT NULL,
duration VARCHAR(50)
);

Enrollments Table

CREATE TABLE enrollments(
enrollment_id INT PRIMARY KEY AUTO_INCREMENT,
student_id INT,
course_id INT,
enrollment_date DATE,
FOREIGN KEY(student_id)
REFERENCES students(student_id),
FOREIGN KEY(course_id)
REFERENCES courses(course_id)
);

31. Complete JOIN Query for Your Project

SELECT
students.student_id,
students.name,
students.email,
courses.course_name,
courses.duration,
enrollments.enrollment_date
FROM students
INNER JOIN enrollments
ON students.student_id=enrollments.student_id
INNER JOIN courses
ON enrollments.course_id=courses.course_id;

SELECT
courses.course_name,
students.name
FROM courses

ON enrollments.student_id=students.student_id;

34. Finding All Courses with Student Count

SELECT
courses.course_name,
COUNT(enrollments.student_id) AS student_count
FROM courses
LEFT JOIN enrollments
ON courses.course_id=enrollments.course_id
GROUP BY courses.course_id,courses.course_name;

37. JOINs in Your Online Tech Learning Academy

JOINs will be very useful when you connect your website with your database.

  • The students table stores student details.
  • The courses table stores course details.
  • The enrollments table stores which student enrolled in which course.
  • The results table stores student marks.
  • JOINs allow information from these tables to be displayed together.

38. Example of Student Dashboard Query

When a logged-in student opens the My Courses page, a JOIN can retrieve the courses that belong to that student.

SELECT
courses.course_id,
courses.course_name,
courses.duration
FROM enrollments
INNER JOIN courses
ON enrollments.course_id=courses.course_id
WHERE enrollments.student_id=1;

39. Example of Student Results Query

A JOIN can also display the student's course name along with marks.

SELECT
students.name,
courses.course_name,
results.marks
FROM results
INNER JOIN students
ON results.student_id=students.student_id
INNER JOIN courses
ON results.course_id=courses.course_id
WHERE students.student_id=1;

40. Important Points to Remember

  1. JOINs combine data from multiple tables.
  2. INNER JOIN returns matching records.
  3. LEFT JOIN returns all records from the left table.
  4. RIGHT JOIN returns all records from the right table.
  5. FULL OUTER JOIN returns records from both tables, where supported.
  6. MySQL can simulate FULL OUTER JOIN using UNION.
  7. CROSS JOIN creates all possible combinations.
  8. SELF JOIN joins a table with itself.
  9. The ON clause specifies the relationship between tables.
  10. WHERE filters the result.
  11. Aliases make long JOIN queries easier to understand.
  12. Multiple tables can be joined in one query.
  13. JOIN can be combined with WHERE, GROUP BY, HAVING and ORDER BY.
  14. JOINs are essential when working with relational databases.
  15. JOINs will be important for your student, course, enrollment and result tables.
