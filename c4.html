CSS Lesson 4: Layout, Display, Positioning and Flexbox

1. Introduction to CSS Layout

CSS layout controls how HTML elements are arranged and positioned on a webpage.

CSS provides several properties and techniques for creating layouts.

The important layout concepts include:

  • Display
  • Position
  • Float
  • Flexbox
  • Alignment
  • Gap
  • Responsive layout

2. Display Property

The display property specifies how an HTML element should be displayed.

Common Display Values

Value Description
block Element takes the full available width.
inline Element takes only the required width.
inline-block Behaves like inline but allows width and height.
none Element is completely removed from the layout.
flex Creates a flexible layout.
grid Creates a grid-based layout.

3. Display Block

A block-level element normally starts on a new line and takes the available width.

Example

div{
display:block;
}

Common block elements include div, p, h1 and section.

4. Display Inline

Inline elements do not normally start on a new line and occupy only the space required by their content.

Example

span{
display:inline;
}

Common inline elements include span, a and strong.

5. Display Inline-Block

inline-block combines characteristics of inline and block elements.

Elements can appear on the same line while still allowing width and height.

Example

button{
display:inline-block;
width:150px;
height:50px;
}

6. Display None

The display:none property completely hides an element from the page layout.

Example

.menu{
display:none;
}

This technique is commonly used with JavaScript to show and hide menus.

7. Position Property

The position property specifies how an element is positioned on a webpage.

The main position values are:

  • static
  • relative
  • absolute
  • fixed
  • sticky

8. Position Static

static is the default position of HTML elements.

Example

div{
position:static;
}

Top, right, bottom and left properties do not affect a static element.

9. Position Relative

position:relative positions an element relative to its normal position.

Example

div{
position:relative;
top:20px;
left:30px;
}

The element moves from its normal position while its original space remains in the layout.

10. Position Absolute

position:absolute positions an element relative to its nearest positioned ancestor.

Example

.box{
position:absolute;
top:100px;
left:50px;
}

An absolutely positioned element is removed from the normal document flow.

11. Position Fixed

position:fixed keeps an element fixed relative to the browser window.

Example

nav{
position:fixed;
top:0;
left:0;
width:100%;
}

This is exactly the technique used for the navigation bar of your project.

12. Position Sticky

position:sticky behaves like a normal element until a specified position is reached while scrolling.

Example

h2{
position:sticky;
top:70px;
}

13. Top, Right, Bottom and Left

The top, right, bottom and left properties are used with positioned elements.

Example

.box{
position:absolute;
top:50px;
right:30px;
}

14. Z-Index

The z-index property controls the stacking order of positioned elements.

Example

nav{
position:fixed;
z-index:1000;
}

An element with a higher z-index normally appears above an element with a lower z-index.

15. CSS Flexbox

Flexbox is a CSS layout system used to arrange elements in rows or columns.

It makes it easier to create flexible and responsive layouts.

Basic Syntax

.container{
display:flex;
}

16. Flex Container

An element becomes a flex container when display:flex is applied to it.

Example

.container{
display:flex;
}

The direct children of the container become flex items.

17. Flex Direction

The flex-direction property specifies the direction of flex items.

Values

Value Description
row Items are arranged horizontally.
row-reverse Items are arranged horizontally in reverse order.
column Items are arranged vertically.
column-reverse Items are arranged vertically in reverse order.

Example

.container{
display:flex;
flex-direction:row;
}

18. Justify Content

The justify-content property controls the alignment of flex items along the main axis.

Common Values

Value Purpose
flex-start Items start from the beginning.
flex-end Items move to the end.
center Items are centered.
space-between Equal space is placed between items.
space-around Space is placed around items.
space-evenly Equal space is placed between and around items.

Example

.container{
display:flex;
justify-content:center;
}

19. Align Items

The align-items property controls alignment along the cross axis.

Example

.container{
display:flex;
align-items:center;
}

This is commonly used to vertically center elements.

20. Flex Wrap

The flex-wrap property controls whether flex items should move to another line when there is not enough space.

Example

.container{
display:flex;
flex-wrap:wrap;
}

This is useful when creating responsive course cards.

21. Gap

The gap property creates space between flex items.

Example

.container{
display:flex;
gap:20px;
}

22. Flex Grow

The flex-grow property controls how much a flex item can grow relative to other items.

Example

.box{
flex-grow:1;
}

23. Flex Shrink

The flex-shrink property controls how much a flex item can shrink when there is not enough space.

Example

.box{
flex-shrink:1;
}

24. Flex Basis

The flex-basis property specifies the initial size of a flex item.

Example

.box{
flex-basis:200px;
}

25. Flex Shorthand

The flex property is a shorthand for flex-grow, flex-shrink and flex-basis.

Example

.box{
flex:1;
}

26. Align Self

The align-self property allows one flex item to have a different alignment from the other items.

Example

.box{
align-self:flex-end;
}

27. Order Property

The order property changes the visual order of flex items.

Example

.box1{
order:2;
}

.box2{
order:1;
}

28. Flexbox Example

<div class="container">

<div class="box">HTML</div>

<div class="box">CSS</div>

<div class="box">JavaScript</div>

</div>

<style>

.container{
display:flex;
justify-content:center;
align-items:center;
gap:20px;
flex-wrap:wrap;
}

.box{
width:200px;
padding:30px;
background-color:#1e3a5f;
color:#40E0D0;
border:2px solid #40E0D0;
text-align:center;
border-radius:10px;
}

</style>

29. Float

The float property was traditionally used to position elements to the left or right.

Example

img{
float:left;
margin-right:20px;
}

Modern layouts generally use Flexbox or Grid instead of float.

30. Clear Property

The clear property controls whether an element can appear beside floated elements.

Example

div{
clear:both;
}

31. CSS Grid Introduction

CSS Grid is another powerful layout system that allows elements to be arranged in rows and columns.

Example

.container{
display:grid;
grid-template-columns:1fr 1fr 1fr;
gap:20px;
}

32. Grid Columns

The grid-template-columns property specifies the number and size of grid columns.

Example

.container{
display:grid;
grid-template-columns:repeat(3,1fr);
}

33. Grid Gap

The gap property can also be used with CSS Grid to create space between rows and columns.

Example

.container{
display:grid;
gap:20px;
}

34. Flexbox vs Grid

Flexbox Grid
One-dimensional layout. Two-dimensional layout.
Works mainly with rows or columns. Works with rows and columns.
Excellent for navigation bars. Excellent for complex page layouts.
Useful for arranging items in one direction. Useful for arranging items in two directions.

35. Responsive Flexbox Layout

Flexbox can help create layouts that automatically adjust according to screen size.

Example

.container{
display:flex;
flex-wrap:wrap;
gap:20px;
}

.card{
flex:1 1 250px;
}

36. Navigation Bar Using Flexbox

Your project navigation bar uses Flexbox.

nav{
display:flex;
align-items:center;
gap:10px;
}

display:flex places the navigation elements in a flexible layout.

align-items:center vertically centers the items.

gap:10px creates space between the navigation items.

37. Student Dashboard Using Positioning

Your student dashboard also uses CSS positioning.

.student-dashboard{
margin-left:auto;
position:relative;
}

.student-menu{
display:none;
position:absolute;
top:65px;
right:0;
}

The dashboard menu is positioned relative to the student dashboard container.

39. Important CSS Layout Properties

Property Purpose
display Controls how an element is displayed.
position Controls element positioning.
top Moves a positioned element from the top.
right Moves a positioned element from the right.
bottom Moves a positioned element from the bottom.
left Moves a positioned element from the left.
z-index Controls stacking order.
display:flex Creates a Flexbox container.
flex-direction Controls the direction of flex items.
justify-content Aligns items along the main axis.
align-items Aligns items along the cross axis.
flex-wrap Controls whether items wrap.
gap Creates space between items.
display:grid Creates a CSS Grid layout.

40. Important Points to Remember

  1. The display property controls how an element is displayed.
  2. Block elements normally occupy the available width.
  3. Inline elements occupy only the required space.
  4. inline-block allows width and height while keeping elements inline.
  5. display:none hides an element completely.
  6. The position property controls how an element is positioned.
  7. The main position values are static, relative, absolute, fixed and sticky.
  8. z-index controls the stacking order of elements.
  9. Flexbox is used to create flexible one-dimensional layouts.
  10. justify-content controls alignment along the main axis.
  11. align-items controls alignment along the cross axis.
  12. flex-wrap allows flex items to move to another line.
  13. gap creates space between flex items.
  14. CSS Grid is useful for two-dimensional layouts.
  15. Flexbox is commonly useful for navigation bars and cards.
  16. Grid is useful for layouts involving rows and columns.

Lesson Summary

In this lesson, you learned how CSS controls the layout and positioning of elements on a webpage.

You learned about the display property, different positioning methods, z-index and Flexbox.

You also learned important Flexbox properties such as flex-direction, justify-content, align-items, flex-wrap and gap.

CSS Grid was introduced as another method for creating two-dimensional layouts.

These concepts are especially useful for your Online Tech Learning Academy project because they can be used to create navigation bars, course cards, dashboards, forms and responsive layouts.
