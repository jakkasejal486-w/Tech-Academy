CSS Lesson 3: CSS Box Model

1. Introduction to CSS Box Model

The CSS Box Model describes how every HTML element is represented as a rectangular box on a webpage.

Every element consists of different areas that control its size and spacing.

The four main parts of the CSS Box Model are:

  1. Content
  2. Padding
  3. Border
  4. Margin

The Box Model is one of the most important concepts in CSS because it helps us control the size, spacing and position of elements.

2. Structure of the Box Model

The CSS Box Model can be represented as:

+---------------------------------------+
|                Margin                 |
|   +-------------------------------+   |
|   |            Border             |   |
|   |   +-----------------------+   |   |
|   |   |       Padding         |   |   |
|   |   |   +---------------+   |   |   |
|   |   |   |    Content    |   |   |   |
|   |   |   +---------------+   |   |   |
|   |   +-----------------------+   |   |
|   +-------------------------------+   |
+---------------------------------------+

3. Four Parts of Box Model

Part Purpose
Content The actual text, image or other content inside the element.
Padding Space between the content and the border.
Border Line surrounding the padding and content.
Margin Space outside the border.

4. Content

The content area contains the actual content of an HTML element.

This can include text, images, videos, forms or other HTML elements.

Example

div{
width:300px;
height:150px;
}

Here, the content area has a width of 300px and a height of 150px.

5. Width Property

The width property specifies the width of an element.

Example

div{
width:300px;
}

6. Height Property

The height property specifies the height of an element.

Example

div{
height:200px;
}

7. Padding

Padding is the space between the content of an element and its border.

Padding is inside the border.

Example

div{
padding:20px;
}

This adds 20px of padding on all four sides.

8. Padding on Individual Sides

Padding can be specified separately for the top, right, bottom and left sides.

Example

div{
padding-top:10px;
padding-right:20px;
padding-bottom:30px;
padding-left:40px;
}

9. Padding Shorthand

The padding shorthand property can be used to specify padding for multiple sides.

One Value

div{
padding:20px;
}

All four sides receive 20px padding.

Two Values

div{
padding:10px 20px;
}

The first value applies to top and bottom.

The second value applies to left and right.

Four Values

div{
padding:10px 20px 30px 40px;
}

The values are applied in this order:

top
right
bottom
left

10. Border

A border is a line surrounding the content and padding of an element.

Example

div{
border:2px solid #40E0D0;
}

11. Border Width

The border-width property controls the thickness of the border.

Example

div{
border-width:3px;
}

12. Border Style

The border-style property specifies the style of the border.

Common Border Styles

Style Description
solid Creates a solid line.
dashed Creates a dashed line.
dotted Creates a dotted line.
double Creates a double line.
none Removes the border.

Example

div{
border-style:solid;
}

13. Border Color

The border-color property specifies the color of the border.

Example

div{
border-color:#40E0D0;
}

14. Border Shorthand

The border shorthand allows width, style and color to be specified in one declaration.

Example

div{
border:2px solid #40E0D0;
}

15. Individual Borders

Different borders can be applied to individual sides.

Example

div{
border-top:2px solid #40E0D0;
border-right:2px solid white;
border-bottom:2px solid #40E0D0;
border-left:2px solid white;
}

16. Border Radius

The border-radius property is used to create rounded corners.

Example

div{
border:2px solid #40E0D0;
border-radius:10px;
}

17. Circular Elements

A border radius of 50% can be used to create a circular element when the element has equal width and height.

Example

.circle{
width:100px;
height:100px;
border-radius:50%;
}

18. Margin

Margin is the space outside the border of an element.

Margin is used to create space between different HTML elements.

Example

div{
margin:20px;
}

19. Individual Margins

Margins can be specified individually for each side.

Example

div{
margin-top:10px;
margin-right:20px;
margin-bottom:30px;
margin-left:40px;
}

20. Margin Shorthand

One Value

div{
margin:20px;
}

All four sides receive 20px margin.

Two Values

div{
margin:10px 20px;
}

Top and bottom receive 10px.

Left and right receive 20px.

Four Values

div{
margin:10px 20px 30px 40px;
}

The order is top, right, bottom and left.

21. Auto Margin

The auto value can be used to automatically calculate available margin space.

It is commonly used to center a block element horizontally when it has a defined width.

Example

div{
width:500px;
margin:auto;
}

22. Difference Between Padding and Margin

Padding Margin
Space inside the border. Space outside the border.
Creates space around the content. Creates space between elements.
Background can extend into the padding area. Margin is outside the element's border.

23. Box Sizing

The box-sizing property controls how the width and height of an element are calculated.

The two important values are:

  • content-box
  • border-box

24. Content-Box

content-box is the default box-sizing behavior.

With content-box, the specified width and height apply only to the content area.

Example

div{
box-sizing:content-box;
width:300px;
padding:20px;
border:5px solid #40E0D0;
}

The padding and border are added outside the specified content width.

25. Border-Box

With border-box, the specified width and height include the content, padding and border.

Example

div{
box-sizing:border-box;
width:300px;
padding:20px;
border:5px solid #40E0D0;
}

This makes it easier to control the total size of an element.

26. Universal Box Sizing

A common CSS practice is to apply box-sizing:border-box to all elements.

Example

*{
box-sizing:border-box;
}

This is also used in your project CSS.

27. Total Width of an Element

When using the default content-box, the total width can be calculated using:

Total Width =
Content Width
+ Left Padding
+ Right Padding
+ Left Border
+ Right Border
+ Left Margin
+ Right Margin

28. Total Height of an Element

The total height can similarly be calculated using:

Total Height =
Content Height
+ Top Padding
+ Bottom Padding
+ Top Border
+ Bottom Border
+ Top Margin
+ Bottom Margin

29. Width and Height with Border-Box

When box-sizing:border-box is used, the specified width includes the content and padding and border.

Example

div{
width:300px;
height:200px;
padding:20px;
border:5px solid #40E0D0;
box-sizing:border-box;
}

The total width remains 300px and the total height remains 200px, excluding margins.

30. Outline

An outline is a line drawn around an element, outside its border.

Example

div{
border:2px solid #40E0D0;
outline:2px solid white;
}

31. Outline Width

div{
outline-width:3px;
}

32. Outline Style

div{
outline-style:solid;
}

33. Outline Color

div{
outline-color:#40E0D0;
}

34. Outline Offset

The outline-offset property controls the space between the border and outline.

Example

div{
outline:2px solid #40E0D0;
outline-offset:5px;
}

35. Overflow

The overflow property controls what happens when content is larger than the element's specified dimensions.

Common Values

Value Purpose
visible Content remains visible outside the box.
hidden Extra content is hidden.
scroll Scrollbars are displayed.
auto Scrollbars appear when necessary.

Example

div{
width:300px;
height:100px;
overflow:auto;
}

36. Box Shadow

The box-shadow property adds a shadow around an element.

Syntax

box-shadow:
horizontal
vertical
blur
color;

Example

div{
box-shadow:0 5px 20px rgba(0,0,0,0.5);
}

37. Complete Box Model Example

<!DOCTYPE html>

<html>

<head>

<title>CSS Box Model</title>

<style>

*{
box-sizing:border-box;
}

body{
background-color:black;
font-family:Arial,sans-serif;
}

.box{
width:500px;
height:250px;
background-color:#1e3a5f;
color:white;
padding:30px;
border:3px solid #40E0D0;
margin:50px auto;
border-radius:10px;
box-shadow:0 5px 20px rgba(0,0,0,0.5);
}

</style>

</head>

<body>

<div class="box">

<h2>
CSS Box Model
</h2>

<p>
This element demonstrates
content, padding, border
and margin.
</p>

</div>

</body>

</html>

38. Box Model Properties

Property Purpose
width Controls element width.
height Controls element height.
padding Creates space inside the border.
margin Creates space outside the border.
border Creates a border around the element.
border-radius Creates rounded corners.
box-sizing Controls how width and height are calculated.
outline Creates a line outside the border.
outline-offset Controls space between border and outline.
overflow Controls content that exceeds the element's box.
box-shadow Adds a shadow around the element.

39. Practical Example for Your Project

The CSS Box Model is useful for designing course cards, registration forms, buttons, navigation menus and sections in your Online Tech Learning Academy.

Course Card Example

.course-card{
width:350px;
background-color:#1e3a5f;
color:white;
padding:25px;
border:2px solid #40E0D0;
margin:20px;
border-radius:15px;
box-shadow:0 5px 20px rgba(0,0,0,0.5);
}

Button Example

button{
padding:12px 25px;
margin:10px;
border:2px solid #40E0D0;
border-radius:8px;
background-color:#1e3a5f;
color:#40E0D0;
}

Form Example

form{
width:500px;
padding:30px;
margin:30px auto;
border:2px solid #40E0D0;
border-radius:10px;
}

40. Important Points to Remember

  1. The CSS Box Model describes the rectangular box surrounding every HTML element.
  2. The four main parts are content, padding, border and margin.
  3. Content contains the actual text, image or other content.
  4. Padding creates space between content and border.
  5. Border surrounds the content and padding.
  6. Margin creates space outside the border.
  7. The width property controls the width of an element.
  8. The height property controls the height of an element.
  9. The padding property creates internal spacing.
  10. The margin property creates external spacing.
  11. The border property creates a border around an element.
  12. The border-radius property creates rounded corners.
  13. The box-sizing property controls how element dimensions are calculated.
  14. border-box includes padding and border within the specified width and height.
  15. The outline property creates an outline outside the border.
  16. The overflow property controls content that exceeds the box.
  17. The box-shadow property adds a shadow around an element.
  18. The Box Model is very important for creating proper webpage layouts.

Lesson Summary

In this lesson, you learned the CSS Box Model and how it controls the size and spacing of HTML elements.

You learned about content, padding, border and margin.

You also learned how to control individual sides using top, right, bottom and left properties.

The lesson also covered border styles, border radius, box sizing, outlines, overflow and box shadows.

The box-sizing:border-box property is especially useful when creating organized and responsive webpage layouts.

These concepts will help you design course cards, forms, buttons, navigation bars and other sections of your Online Tech Learning Academy.
