HTML Lesson 1: HTML Basics

1. What is HTML?

HTML stands for HyperText Markup Language.

HTML is the standard markup language used to create and structure web pages.

HTML tells the browser what different parts of a webpage are, such as headings, paragraphs, images, links, tables and forms.

Example

<h1>Online Tech Learning Academy</h1>
<p>Welcome to our website.</p>

The browser reads the HTML code and displays the content as a webpage.

2. What is HyperText?

HyperText means text that contains links to other pages or resources.

Example

<a href="https://www.google.com">Visit Google</a>

When the user clicks Visit Google, the browser opens the linked page.

3. What is Markup Language?

HTML is called a markup language because we use special tags to mark and describe different parts of a webpage.

Example

<h1>This is a heading</h1>

Here:

  • <h1> is the opening tag.
  • This is a heading is the content.
  • </h1> is the closing tag.

Together, they form an HTML element.

4. HTML Tags

HTML uses tags to define different elements on a webpage.

Example

<p>Hello World</p>
Tag Purpose
<html> Defines the HTML document
<head> Contains information about the webpage
<title> Defines the webpage title
<body> Contains visible webpage content
<h1> Main heading
<h2> Second-level heading
<p> Paragraph
<br> Line break
<hr> Horizontal line
<a> Hyperlink
<img> Image
<ul> Unordered list
<ol> Ordered list
<li> List item

5. Opening and Closing Tags

Most HTML elements have an opening tag and a closing tag.

Example

<p>This is a paragraph.</p>

The opening tag is:

<p>

The closing tag is:

</p>

The / indicates the closing tag.

6. HTML Element

An HTML element normally consists of:

Opening Tag + Content + Closing Tag

Example

<h1>My Website</h1>
  • <h1> → Opening tag
  • My Website → Content
  • </h1> → Closing tag

7. Basic Structure of an HTML Document

Every basic HTML webpage follows a structure like this:

<!DOCTYPE html>
<html>
<head>
<title>My Website</title>
</head>
<body>
<h1>Welcome to My Website</h1>
<p>This is my first webpage.</p>
</body>
</html>

DOCTYPE Declaration

<!DOCTYPE html>

It tells the browser that the document uses HTML5.

<html> Element

The <html> element is the root element of the webpage.

<html>
</html>

<head> Element

The <head> contains information about the webpage that is not normally displayed as the main page content.

<head>
<title>My Website</title>
</head>

<title> Element

The <title> defines the title shown in the browser tab.

<title>Online Tech Learning Academy</title>

<body> Element

The <body> contains the visible content of the webpage.

<body>
<h1>Welcome</h1>
<p>This is my website.</p>
</body>

8. Complete First HTML Program

Create a file named index.html and write the following code:

<!DOCTYPE html>
<html>
<head>
<title>My First Webpage</title>
</head>
<body>
<h1>Welcome to My Website</h1>
<h2>About Me</h2>
<p>My name is Sejal.</p>
<p>I am learning HTML.</p>
</body>
</html>

9. HTML Headings

HTML provides six levels of headings.

<h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>

<h1> is the main and most important heading, while <h6> is the lowest-level heading.

10. Paragraph Tag

The <p> tag is used to create a paragraph.

Example

<p>This is my first paragraph.</p>
<p>This is my second paragraph.</p>

11. Line Break

The <br> tag is used to move content to the next line.

Example

<p>Hello<br>Welcome to my website.</p>

The <br> tag does not require a closing tag.

12. Horizontal Line

The <hr> tag creates a horizontal line.

Example

<h1>Courses</h1>
<hr>
<p>Learn HTML, CSS and JavaScript.</p>

13. HTML Attributes

Attributes provide additional information about an HTML element.

Attributes are written inside the opening tag.

Example

<a href="https://www.google.com">Google</a>

14. The href Attribute

The href attribute specifies the destination of a link.

<a href="https://www.google.com">Google</a>

15. The src Attribute

The src attribute specifies the source of an image or other resource.

<img src="photo.jpg">

16. The alt Attribute

The alt attribute provides alternative text for an image.

<img src="student.jpg" alt="Student">

If the image cannot be displayed, the alternative text can help describe the image.

17. HTML Comments

Comments are notes written inside HTML code that are not displayed on the webpage.

Syntax

<!-- This is a comment -->

18. Nested HTML Elements

An HTML element can contain another HTML element. This is called nesting.

Example

<p>Welcome to <b>my website</b>.</p>

19. Proper Nesting

Correct

<p>This is <b>important</b>.</p>

Incorrect

<p>This is <b>important</p></b>

20. HTML File Extension

HTML files normally use the .html extension.

index.html
home.html
about.html
courses.html
contact.html
login.html

21. Connecting Multiple HTML Pages

Different HTML pages can be connected using the <a> tag.

<a href="index.html">Home</a>
<a href="about.html">About</a>
<a href="courses.html">Courses</a>
<a href="contact.html">Contact</a>

22. Important HTML Terms

Tag

A tag is a markup keyword enclosed inside angle brackets.

<p>

Element

An element normally consists of an opening tag, content and a closing tag.

<p>Hello</p>

Attribute

An attribute provides additional information about an HTML element.

<a href="page.html">Open Page</a>

Content

Content is the information between the opening and closing tags.

<p>Hello World</p>

23. Important Points to Remember

  1. HTML stands for HyperText Markup Language.
  2. HTML is used to create and structure webpages.
  3. HTML uses tags to define webpage elements.
  4. Most HTML elements have opening and closing tags.
  5. <html> is the root element.
  6. <head> contains webpage information.
  7. <title> defines the browser-tab title.
  8. <body> contains visible webpage content.
  9. <h1> to <h6> are heading tags.
  10. <p> is used for paragraphs.
  11. <a> is used for links.
  12. <img> is used for images.
  13. href specifies a link destination.
  14. src specifies a resource source.
  15. alt provides alternative text for images.
  16. <br> creates a line break.
  17. <hr> creates a horizontal line.
  18. <!-- --> creates a comment.
  19. HTML files normally use the .html extension.
  20. <!DOCTYPE html> declares an HTML5 document.

Lesson Summary

HTML is the foundation of a webpage. In this lesson, you learned about HTML structure, tags, elements, attributes, headings, paragraphs, links, images, comments, nesting and connecting multiple HTML pages.
